# 权限 \& 多租户隔离规范

## 文档描述

本规范基于集团多业态、集团 \+ 子公司两级管控架构制定，统一系统 RBAC 功能权限、数据多租户隔离、分级二级审核、菜单权限、前端按钮鉴、数据过滤、审计追溯全套标准；完全对齐《集团多业态一体化管控系统整体方案》《模块权限归属清单》《后端编码规范》《前后端开发规范》，单人开发统一权限设计逻辑，解决跨公司数据泄露、越权操作、高危单人操作风险，满足内控、等保合规要求。

## 一、基础定义与核心设计原则

### 1\.1 三类模块归属权限定义

1. **【集团独有】**：仅集团管理员可新增 / 编辑 / 配置；子公司无菜单、无操作权限，仅可查看本公司基础数据。
适用：全局角色模板、流程模板、财务合并报表、全域数据大屏、营销全局规则、跨子公司调拨审批、全量审计日志。

2. **【子公司独有】**：子公司运营人员自主业务操作；集团仅拥有只读汇总查看权限，不能新增 / 修改 / 删除子公司任何业务单据。
适用：铺位租赁、市场地图、水电收费、**自定义收费规则（收费项 / 收费规则 / 周期账单）**、自有仓库、本公司 OA、招商线索、活动运营。

3. **【全集团共享（双向数据隔离）】**：一套页面一套代码，按`company_id`自动隔离数据；集团看全量，子公司仅看自身数据。
适用公文、审批中心、考勤、工作汇报、全局财务流水台账。

### 1\.2 四大核心原则

1. **配置归集团，操作归子公司，查看分层**：全局参数、模板、规则统一由集团管控，业务落地操作下放各子公司。

2. **功能 \+ 数据双层权限防护**：先校验菜单 / 按钮功能权限，再自动过滤所属公司数据，双重防越权。

3. **轻重权限分级管控**：普通日常权限单人即时生效；地图 / 财务 / 全局配置等高敏感权限强制双人二级复核。

4. **全数据带归属隔离**：所有业务数据表强制携带`company_id`，物理同库、逻辑隔离，杜绝跨公司数据互通。

## 二、RBAC 功能权限整体设计

### 2\.1 账号身份分层体系

1. **集团超级管理员**：最高权限，可配置全局角色、审批敏感权限变更、查看全集团所有业务 / 财务 / 审计数据，拥有二级复核审批权限。

2. **集团运维管理员**：中台运维岗，负责账号开通、普通权限分配、敏感权限发起申请，无复核审批权。

3. **子公司管理员**：管理本公司全部业务、OA 账号，仅操作本公司数据，无跨公司配置权限。

4. **子公司普通员工**：仅查看本人关联单据、提交申请，无批量编辑 / 导出 / 删除权限。

5. **商户小程序账号**：独立外部账号体系，仅绑定自身铺位，无后台登录入口，仅查询账单缴费。

### 2\.2 权限标识编码规范（全局统一）

编码格式：`模块:操作`

1. 基础查询：`stall:list`、`stall:map:list`

2. 新增：`stall:add`

3. 编辑：`stall:edit`

4. 删除：`stall:delete`

5. 导出 / 打印：`stall:map:export`

6. 特殊高危编辑（地图底图 / 批量点位）：`stall:map:edit`
示例清单（铺位地图专项）：

- stall:map:list 铺位地图页面查看（普通权限）

- stall:map:edit 底图上传、画布绘制、批量点位修改、删除地图（敏感权限，二级复核）

- stall:map:export 地图导出打印（普通权限）

示例清单（财务自定义收费规则专项）：

- fee:item:list 收费项查看（普通权限）

- fee:item:add 收费项新增（普通权限）

- fee:item:edit 收费项编辑（普通权限）

- fee:item:delete 收费项删除（普通权限）

- fee:rule:list 收费规则查看（普通权限）

- fee:rule:add 收费规则新增（普通权限）

- fee:rule:edit 收费规则编辑（普通权限）

- fee:rule:delete 收费规则删除（普通权限）

- fee:rule:bind 规则绑定 / 解绑铺位、单铺位覆盖配置（普通权限，变更留审计）

- fee:bill:list 收费账单查看（普通权限）

- fee:bill:generate 周期账单批量生成（普通权限，幂等）

- fee:bill:adjust 账单人工调账（**敏感操作**，需二次确认弹窗，强制审计日志）

### 2\.3 后端权限校验规范

1. 所有 Controller 接口必须添加注解：`@PreAuthorize("hasPermission('xxx:xxx')")`，无权限直接返回 403，不依赖前端隐藏按钮。

2. 权限数据存入 JWT 令牌，登录时加载当前用户全部权限集合，全局拦截器统一校验。

3. 权限变更实时生效，无需重启服务。

### 2\.4 前端按钮 / 页面权限规范

1. 页面路由 meta 绑定`permission`，无权限路由拦截跳转 403 页面。

2. 所有操作按钮统一使用`<AuthBtn permission="xxx:xxx">`组件，无权限自动隐藏。

3. 禁止通过 v\-if 手动判断权限，统一封装组件，保证前后端权限标识完全一致。

## 三、多租户 company\_id 数据隔离规范（核心）

### 3\.1 数据表隔离区分标准

#### 3\.1\.1 集团全局公共表（无 company\_id）

物资分类、系统字典、全局参数、角色模板、流程模板、集团组织架构。
仅集团可维护，全子公司只读共享。

#### 3\.1\.2 子公司私有业务表（必须携带 company\_id）

铺位、商户、租赁合同、market\_map 市场地图、map\_stall\_point 点位、水电账单、**收费规则（biz\_fee\_item / biz\_fee\_rule / biz\_fee\_rule\_stall\_rel / biz\_fee\_bill / biz\_fee\_bill\_detail）**、物资出入库、公文、考勤、招商线索、营销活动。

> 市场地图双维度隔离：`company_id + market_id`，严格区分不同子公司不同市场平面图。
> 
> 

#### 3\.1\.3 全域共享流水表（biz\_finance\_flow）

统一财务收支流水，每条记录携带 company\_id；

- 子公司视图：自动过滤本公司收支；

- 集团财务视图：全集团汇总对账。

### 3\.2 数据权限拦截技术实现

1. 底层 MyBatis-Plus 自定义拦截器，执行 SQL 自动拼接`WHERE company_id = 当前登录公司ID`；

2. 身份区分逻辑：

    - 集团超级管理员 / 集团财务：关闭自动过滤，查询全部分公司数据；

    - 所有子公司账号：强制追加 company 条件，只能查询自身业务；

3. 特殊白名单场景（集团跨调拨、全域报表）：代码手动关闭拦截器，添加业务注释，全程审计记录。

### 3\.3 业务层数据赋值强制规则

1. 新增任何业务单据、市场地图、商户档案时，后端自动从登录上下文获取`company_id`赋值；

2. 前端禁止传递、篡改 company\_id 参数，接口传入直接丢弃，以服务端上下文为准；
3 铺位画布点位保存时，校验 stall 所属 market、company 与当前操作人匹配，禁止跨公司绑定铺位。

### 3\.4 多业态扩展兼容

新增幼儿园 / 建筑 / 园林等分公司时，仅新增组织档案，无需修改数据隔离底层逻辑，所有模块自动复用 company\_id 隔离机制。

## 四、分级权限二级双人审核机制（风控核心）

### 4\.1 机制设计目标

解决单一运维账号独立开放地图、财务、全局高危权限，导致误操作、数据泄露、违规配置风险；区分普通权限高效流程、敏感权限强制衡流程。

### 4\.2 权限分级划分

#### 4\.2\.1 普通权限（单人即时生效，无需复核）

单人操作、保存后立即生效，仅留存基础操作日志：

1. 普通员工账号新增 / 启用 / 禁用；

2. 基础铺位、巡检、OA 查看 / 编辑权限；

3. 地图基础查看、地图导出打印（stall:map:list、stall:map:export）；

4. 无全局、财务、批量高危操作的常规权限配置。

#### 4\.2\.2 敏感高危权限（强制二级双人复核，暂存不生效）

权限变更申请提交后**不立即生效**，存入待审核记录，需集团超级管理员审批通过才生效；
包含六大类高危权限，新增地图专项敏感项：

1. 全局配置类：角色模板、流程、UI 全局主题、第三方密钥配置；

2. 全域财务类：集团合并报表、跨公司财务查看、财务批量导出；

3. 全域数据大屏、全平台审计日志查看权限；

4. 超级管理员账号、跨子公司数据查看权限；

5. 集团营销全局规则、大额优惠配置权限；

6. **地图高危专属权限（stall:map:edit）**：市场底图上传 / 替换、画布批量点位修改、批量绑定铺位、地图删除。

### 4\.3 二级审核完整流程

1. 发起：集团运维管理员后台提交敏感权限变更，填写变更模块、权限标识、生效范围、操作原因；

2. 暂存：权限状态标记「待审核」，用户无法使用该权限；

3. 复核：集团超级管理员处理，支持【通过 / 驳回 / 退回修改】；

4. 生效 / 作废：

    - 通过：权限正式授予，写入审计日志；

    - 驳回：申请作废，无权限变更。

### 4\.4 岗位权责分离

1. 操作岗（集团运维）：仅可发起权限变更，无最终审批权；

2. 复核岗（集团超级管理员）：仅审批高危权限，不参与日常账号运维；

3. 制衡逻辑：做事的人不能自主开通高危权限，杜绝单人闭环风险。

## 五、菜单与数据权限配套规则

### 5\.1 集团后台菜单权限

仅展示全局配置、全域数据汇总、跨公司审批菜单；无子公司独立业务操作入口，仅可查看各子公司数据统计。

### 5\.2 子公司后台菜单权限

仅展示本公司租赁、地图、水电、物资、OA、营销业务；隐藏全部集团全局配置、全域汇总菜单。

### 5\.3 铺位可视化地图专属权限规则

1. 子公司运营：拥有 stall:map:edit，可上传底图、绘制、编辑画布；

2. 集团所有账号：仅 stall:map:list 只读权限，无画布编辑入口；

3. 地图删除、批量点位修改、替换底图权限属于敏感权限，开通必须走二级复核；

4. 数据隔离：加载地图列表时自动过滤当前 company\_id，看不到其他子公司市场平面图。

### 5\.4 财务自定义收费规则专属权限规则

1. 收费规则归属【子公司可操作、集团可查看】：子公司管理员可新增 / 编辑收费项、收费规则，绑定铺位，生成周期账单；集团所有账号仅 fee:rule:list、fee:bill:list 只读查看，无配置与生成入口；

2. 规则变更留痕：收费项 / 规则新增、编辑、删除、绑定解绑铺位、单铺位覆盖配置全部写入审计日志（oper\_module=fee\_rule / fee\_bill），但属普通权限单人即时生效，无需二级复核；

3. 敏感操作强制审计：账单人工调账（fee:bill:adjust）属敏感操作，前端必须二次确认弹窗，后端强制审计日志记录变更前后金额，大额调账（超集团配置阈值）必须走二级复核；

4. 数据隔离：收费项、规则、账单全部 company\_id 隔离，禁止跨子公司绑定铺位生成账单；集团仅汇总只读，不提供任何子公司收费规则编辑入口。

## 六、审计日志权限追溯规范

### 6\.1 权限操作日志记录范围

1. 普通权限单人变更：记录操作人、时间、变更前后权限；

2. 敏感二级审核权限：完整记录「发起人 \- 复核人 \- 审核状态 \- 变更内容 \- IP」；

3. 地图高危操作（底图替换、点位批量保存、删除地图）单独标记模块类型，独立审计分类。

### 6\.2 日志查看数据隔离

1. 集团管理员：查看全平台所有权限、地图、财务审计记录；

2. 子公司管理员：仅查看本 company\_id 下业务操作日志；

3. 普通员工：仅可查看本人操作记录，无法查看他人 / 全公司审计台账。

## 七、财务 / 营销 / 物资专项权限补充

1. 财务流水：子财务仅看本公司收支，集团财务可合并全集团报表；全域财务导出属于敏感权限，需二级复核。

2. 自定义收费规则：收费项 / 规则 / 周期账单归属子公司私有，子公司自主配置与生成；集团仅只读查看汇总，禁止开放子公司收费规则编辑入口；账单人工调账属敏感操作强制审计，大额调账需二级复核。

3. 营销模块：集团仅配置优惠模板，子公司仅运营自有招商活动，大额优惠权限强制双人审核。

4. 物资跨调拨：仅集团拥有跨分公司调拨审批权限，子公司只能申请、接收本仓库物资。
5. HR 人事模块：员工档案、考勤、薪资数据归属子公司私有，集团仅只读汇总查看，禁止开放子公司 HR 数据编辑入口；人事异动、批量导出属敏感操作强制审计。

## 八、开发强制红线（不可违反）

1. 禁止接口、页面绕过 company\_id 数据过滤，直接全量查询；

2. 禁止高危地图 / 财务 / 全局权限单人直接开通，必须接入二级复核流程；

3. 禁止前端传递、篡改 company\_id，所有数据归属由后端上下文控制；

4. 禁止页面绕过 AuthBtn 组件，硬编码展示新增 / 删除 / 地图编辑按钮；

5. 禁止业务实体、地图数据表缺失 company\_id 字段；

6. 地图画布保存时不校验 stall 所属公司，允许跨子公司绑定点位；

7. 权限变更、地图高危操作不写入审计日志；

8. 集团账号开放子公司业务编辑权限，越权修改商户 / 合同 / 市场地图。
