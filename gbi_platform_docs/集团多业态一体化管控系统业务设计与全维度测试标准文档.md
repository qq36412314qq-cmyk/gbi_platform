# 集团多业态一体化管控系统业务设计与全维度测试标准文档

# 业务设计 \+ 测试文档合集

## 文档描述

本文档为集团多业态一体化管控系统**业务需求设计 \+ 全维度测试标准合并文档**，统一归集全业务模块流程、数据结构、前后端联动规则、验收测试用例、上线自查清单；对齐《集团多业态整体方案》《权限清单》《前后端开发规范》《安全规范》等全部配套技术文档，单人开发一套文档覆盖业务落地、自测验收、上线复盘全流程，分为两大核心板块：业务整体设计、分层测试规范，包含摊位可视化 Fabric 画布专项业务与测试内容。

# 第一部分 全业务设计规范

## 1 业务整体设计总原则

1. 中台统一复用：组织、权限、流程引擎、消息、文件、审计、UI 主题全部公共能力，所有业务模块禁止自建同类底层逻辑；

2. 集团 \- 子公司两级隔离：一套数据库`company_id`逻辑隔离，集团仅查看汇总，子公司自主经营操作；

3. 数据同源闭环：租赁、营销、水电等收支统一归集全域财务流水，杜绝多台账数据不一致；

4. 流程标准化：合同、采购、调拨、报销、公文统一 Flowable 流程引擎，一套审批逻辑全业务复用；

5. 分步落地：一期汽车城租赁 / 水电 / 物资 / 巡检；二期 OA 办公 \+ 营销模块；三期财务打通 \+ 多业态拓展；

6. 模块低耦合：新增业态（幼儿园 / 建筑）仅新增业务层代码，中台、数据隔离、财务底层不动。

## 2 四大板块业务架构设计

### 2\.1 统一中台底座（公共支撑，无独立业务操作页面）

#### 2\.1\.1 组织与账号权限业务设计

1. 组织层级：集团总公司→各业态子公司→部门→员工 / 商户；

2. 账号分类：集团超级管理员、集团运维、子公司管理员、普通员工、商户小程序账号；

3. RBAC 权限分层：功能权限（菜单 / 按钮）\+ 数据权限（company\_id 过滤）；

4. 敏感权限强制二级双人复核：地图编辑、全局配置、财务全域查看等高危权限单人无法直接开通；

5. 权限变更、账号启停、密码修改自动写入审计日志。

#### 2\.1\.2 统一流程引擎业务设计

1. 可视化表单配置，支持条件分支、会签、抄送、催办、退回、转交；

2. 覆盖场景：合同审批、物资调拨、采购、报销、请假、公文、大额营销活动；

3. 统一待办中心：全系统所有审批任务聚合，小程序 / PC 同步消息提醒；

4. 流程节点绑定操作人所属 company\_id，跨子公司单据仅集团可查看。

#### 2\.1\.3 消息与文件中台

1. 消息类型：站内信、小程序模板消息、短信、待办提醒；

2. 文件统一 OSS 存储：合同、巡检照片、市场底图、办公文档共用存储池；

3. 文件按 company\_id 隔离，子公司无法访问其他分公司附件；

4. 全局字典、费用参数、审批阈值统一由集团配置，子公司只读。

#### 2\.1\.4 审计日志业务规则

强制记录高危操作，永久归档不可删除：
账号登录退出、权限变更、地图底图 / 点位修改、地图删除、缴费退费、批量导出、全局参数修改、UI 主题配置、第三方密钥变更。

### 2\.2 业务运营板块（一期核心创收业务）

#### 2\.2\.1 摊位租赁管理（含 Fabric 可视化地图模块）

##### （1）基础台账业务流程

摊位建档→商户入驻建档→合同创建（租金 / 押金 / 租期）→审批生效→日常收费→到期续租 / 退租；
到期自动预警，欠费自动推送提醒、远程断电联动水电模块。

##### （2）摊位可视化地图专项业务设计

1. 底图管理流程：子公司上传园区平面图→OSS 存储→后台绑定 market、company；

2. 画布编辑业务：矩形 / 多边形绘制摊位、拖拽调整、绑定 stallId；

3. 状态联动规则：系统实时读取摊位租赁状态，自动上色

    - empty 空置（浅绿）、rent 已租（主蓝）、overdue 欠费（暗红）、expireSoon 即将到期（浅橙）；

4. 点位联动：点击摊位弹窗展示商户、合同、欠费、续租、打印，与台账功能同源；

5. 数据持久：前端 Fabric 序列化 JSON 传给后端存入`market_map.point_json`；

6. 数据一致性校验：保存点位时校验 stall 归属 market/company，禁止跨公司绑定摊位；

7. 权限业务规则：

    - 子公司：拥有 stall:map:edit，可上传底图、编辑点位、删除地图；

    - 集团：仅 stall:list 只读，无编辑；

    - 底图替换、批量点位修改、删除地图属于敏感权限，开通需二级复核；

8. 商户小程序业务：仅展示静态底图，高亮自身摊位，无画布编辑。

##### （3）租赁财务联动

租金、押金、物业费自动写入`biz_finance_flow`统一流水，支持按商户 / 市场 / 分公司对账；营销优惠自动抵扣应收金额，流水标记优惠类型。

#### 2\.2\.2 水电物业收费 \+ 智能物联网表

1. 设备绑定→定时远程抄表→月度自动生成合并账单（水电 \+ 物业）；

2. 支付渠道：小程序线上缴费、线下人工登记兜底；

3. 费控业务：余额不足预警、欠费远程断电、缴费自动合闸；

4. 计费规则集团统一配置阶梯电价、公摊、逾期罚息，子公司仅启用。

#### 2\.2\.3 集团 \- 子公司两级物资管理

1. 集团侧：统一物资分类编码、集团总库、跨分公司调拨审批、全库存汇总；

2. 子公司侧：自有仓库、采购申请、入库、领用、退库、盘点报废；

3. 业务联动：安全巡检隐患可直接生成物资领用申请；

4. 库存低于安全阈值推送集团 \+ 子公司管理员双预警。

#### 2\.2\.4 安全巡检业务

1. 巡检计划配置（日 / 周 / 月）；

2. 现场打卡拍照→上报隐患→指派责任人→整改→复核闭环；

3. 所有巡检台账永久存档，支持按公司 / 时间段导出统计。

#### 2\.2\.5 财务自定义收费规则（一期核心能力）

**业务定位**：集团汽车城租赁、物业水电收费支持自定义收费项 / 计费规则 / 周期账单，子公司自主配置、集团仅只读查看，一期落地无需改代码。

1. 收费项配置：子公司维护收费项目（租金、物业费、水费、电费、公摊费、押金、违约金、一次性杂费），配置计量单位与备注；集团仅查看；

2. 计费模式（六种，界面表单配置，**禁止脚本式自定义公式**）：
   - 固定金额：每周期固定费用；
   - 按面积：单价 × 摊位面积；
   - 仪表计量：水表 / 电表读数 × 单价，支持阶梯单价（rule\_config\_json 存阶梯档位）；
   - 按租金百分比：附加费用 = 月租金 × 百分比；
   - 逾期违约金：固定金额 / 按逾期本金百分比 / 按日罚息，支持宽限期与罚息上限；
   - 公摊分摊：按面积 / 按户数 / 按用量三种分摊方式。

3. 周期与生效规则：按月 / 季 / 年 / 一次性生成账单；规则带生效 / 失效时间；**历史账单锁定（locked\_flag=1），规则修改只作用于未来周期，不回溯重算旧账单**；一套规则可绑定多个摊位，单摊位支持特殊规则覆盖（override\_price / override\_config\_json）；

4. 减免与调整：规则级折扣率（discount\_rate）、免租期（waive\_months）；账单人工调账（adjust\_amount 正负均可）属敏感操作，前端二次确认、后端强制审计日志，大额调账需二级复核；

5. 账单生成与财务联动：按周期批量生成账单（同一公司同一摊位同一周期唯一，幂等跳过），金额公式 real\_amount = original\_amount \- discount\_amount + adjust\_amount，明细表快照固化收费项名称 / 单价 / 计费基数；生成与调账均同步写入 biz\_finance\_flow 统一流水（business\_type=fee\_bill），缴费复用通用缴费幂等接口；

6. 数据隔离与审计：收费项、规则、绑定、账单、明细全部 company\_id 隔离，禁止跨子公司绑定摊位 / 生成账单；收费项与规则变更、绑定解绑、调账全部写入审计日志（oper\_module=fee\_rule / fee\_bill）。

#### 2\.2\.6 全域营销运营模块（二期新增拓客闭环）

1. 集团配置层：优惠模板、老带新奖励、营销审批阈值；

2. 子公司业务闭环：招商线索录入→跟进→意向→签约入驻；

3. 活动运营：新建活动→配置优惠→审批→小程序展示→报名核销；

4. 商户分层标签：优质 / 即将到期 / 欠费 / 空置摊位，定向推送续租优惠；

5. 老带新：老商户推荐新客，签约后自动发放租金抵扣奖励；

6. 财务联动：所有优惠核销同步财务流水，生成「原价 \- 优惠 = 实收」对账记录。

### 2\.3 集团 OA 办公板块（二期上线）

统一复用流程引擎，所有单据流程化审批：

1. 公文：收文登记、拟稿签发、传阅归档；

2. 通用审批：请假、出差、采购、报销；

3. 会议管理：会议室预约、纪要归档；

4. 公告：定向分公司 / 部门发布，统计已读未读；

5. 考勤：定位打卡、出差记录、考勤报表；

6. 工作汇报：日报 / 周报 / 月报逐级批阅；

7. 个人云盘：合同、办公文档统一存储，文件分公司隔离。

### 2\.4 财务与数据分析板块（二 / 三期迭代）

#### 2\.4\.1 业务财务台账（轻量化二期）

全业务收支统一归集`biz_finance_flow`，双视图：

1. 子公司财务视图：仅查看本公司收支、单据对账、凭证标记；

2. 集团财务视图：全集团汇总、分公司营收对比、合并报表。

#### 2\.4\.2 三期财务深度对接

业务单据自动生成财务凭证，系统与财务软件自动对账，减少手工录入。

#### 2\.4\.3 集团数据大屏

全域经营可视化：租赁营收、欠费总额、物资库存、巡检隐患、营销招商数据，仅集团账号可查看。

## 3 多租户（集团 \- 子公司）数据业务设计

### 3\.1 数据隔离业务规则

1. 所有业务表强制携带`company_id`；

2. 集团公共配置表（字典 / 物资分类 / 流程模板）无 company\_id，全公司共享；

3. 市场地图双维度隔离：company\_id\+market\_id，一个子公司看不到其他市场点位；

4. 前端所有列表、画布加载数据时，后端自动过滤本公司数据，前端无数据过滤逻辑。

### 3\.2 数据表分类业务定义

1. 集团全局表：集团统一维护，子公司只读；

2. 子公司私有业务表：摊位、地图、水电、物资、OA，数据归属分公司；

3. 全域财务流水表：唯一资金数据源，全集团共用，自动分视图；

4. 地图专属表：market\_map（地图主表）、map\_stall\_point（点位明细表，可选），存储画布 JSON 布局。

### 3\.3 跨子公司业务限制

仅物资调拨支持跨分公司交互，其余租赁、地图、OA、财务数据默认隔离，不可跨公司操作。

## 4 第三方对接业务设计

1. OSS 文件：底图、合同、巡检照片统一上传，按 company 分目录隔离；

2. 智能水电网关：定时拉取读数，远程合闸 / 断电；

3. 支付：微信 / 支付宝，缴费、退款幂等处理，回调自动同步账单状态；

4. 金蝶财务：三期凭证自动推送；

5. 短信 / 小程序通知：统一消息中台推送。

## 5 业务开发强制红线

1. 禁止业务自建审批、消息、文件存储，必须复用中台公共能力；

2. 禁止子公司跨 company\_id 操作摊位、地图、财务数据；

3. 禁止收支不写入统一财务流水，单独建收支表；

4. 地图画布点位禁止前端本地持久化，全部后端数据库存储；

5. 高危操作（删除地图、批量点位修改）无二级复核流程禁止上线；

6. 禁止财务、审计、地图数据物理删除，仅逻辑删除；

7. 禁止绕过流程引擎直接保存合同、调拨、报销单据。

# 第二部分 全维度测试规范

## 1 测试整体设计原则

1. 分层测试：单元测试→接口测试→功能业务测试→权限数据隔离测试→安全测试→性能测试；

2. 模块全覆盖：租赁（含 Fabric 地图）、水电、物资、OA、营销、财务、中台；

3. 重点专项测试：多租户越权、资金财务、画布地图、高危权限复核、文件上传、注入攻击；

4. 上线前必须完成完整自查清单，所有用例通过才可打包发布；

5. 测试记录留存，问题标注优先级（阻断 / 严重 / 一般 / 优化）。

## 2 分层测试标准

### 2\.1 后端单元测试（Service 层）

1. 覆盖所有新增 / 编辑 / 删除 / 查询核心业务方法；

2. 测试事务回滚：缴费失败、点位保存异常、调拨出错是否完整回滚；

3. 数据权限过滤测试：传入集团 / 子公司 userId 校验返回数据范围；

4. 入参校验：空值、超长、非法字符是否拦截；

5. 地图专项单元：点位 JSON 非法脚本是否过滤、stall 跨公司绑定拦截。

### 2\.2 API 接口测试规范

#### 2\.2\.1 通用接口测试点

1. 鉴权：无 token / 过期 token 返回 401；

2. 功能权限：无对应 permission 返回 403；

3. 分页接口：不传分页、超大页码、负数页码容错；

4. 幂等接口（缴费、点位保存、核销）重复请求不重复生成数据；

5. 统一返回格式 code/msg/data 校验；

6. 敏感字段脱敏：手机号、身份证、商户证件；

#### 2\.2\.2 摊位地图 7 个接口专项测试

1. getMarketList：子公司仅返回自身地图，集团返回全量；

2. addMarket：非法文件、超大图拦截，company 自动赋值；

3. updateMarket：替换底图正常，跨公司 marketId 无法修改；

4. deleteMarket：无 stall:map:edit 按钮隐藏，删除二次确认；

5. saveMapPoints：

    - 带\<恶意 JSON 自动过滤；

    - stallId 不存在 / 跨公司直接拦截，不入库；

    - 多次保存幂等，不重复生成点位；

6. getMarketDetail：JSON 完整返回，异常地图不崩溃；

7. getStallStatusByMarket：状态枚举全部上色匹配。

### 2\.3 前端功能测试（PC \+ 小程序）

#### 2\.3\.1 页面通用测试

1. 四区块布局统一，弹窗、表单、表格符合规范；

2. AuthBtn 权限按钮无权限自动隐藏；

3. 路由无权限跳转 403；

4. 表单校验提示统一，关闭弹窗清空校验；

5. 导出 / 打印文件名规范，A4 适配。

#### 2\.3\.2 Fabric 画布专项功能测试

1. 双模式切换：集团账号只读，隐藏绘制按钮；

2. 绘制矩形 / 多边形、拖拽缩放、删除点位正常；

3. 撤销 / 重做栈多次操作无错乱；

4. 刷新页面自动还原 JSON 布局；

5. 摊位状态实时刷新，颜色跟随 CSS 主题变量变化；

6. 页面销毁 canvas 实例，无内存溢出；

7. 未保存关闭弹窗提示；

8. JSON 提交前端过滤脚本字符；

9. 摊位点击弹窗联动商户 / 合同数据正常。

#### 2\.3\.3 商户小程序专项测试

1. 无画布编辑功能，仅静态图片；

2. 仅高亮当前商户绑定摊位；

3. 缴费、账单查询流程正常，无后台管理入口。

### 2\.4 多租户 \& 权限专项测试（最高优先级阻断级用例）

#### 2\.4\.1 数据越权测试

1. 使用 A 子公司账号，通过 ID 篡改请求 B 公司地图 / 摊位 / 财务，后端必须拦截，不返回数据；

2. 集团账号可查看所有分公司汇总，不可编辑任何子公司业务；

3. 普通员工仅查看本人关联单据，看不到其他商户数据。

#### 2\.4\.2 二级复核权限测试

1. 开通 stall:map:edit 地图高危权限，单人操作不生效；

2. 集团运维发起申请→超级管理员驳回 / 通过；

3. 通过后按钮显示，驳回无编辑入口；

4. 权限变更完整记录审计日志。

#### 2\.4\.3 菜单权限测试

集团菜单无子公司业务操作入口；子公司隐藏全局配置、全域数据大屏菜单。

### 2\.5 财务资金专项测试（阻断级，不通过禁止上线）

1. 租金 / 物业费 / 营销优惠全部写入 biz\_finance\_flow；

2. 一笔交易异常完整事务回滚，无单边入账；

3. 重复支付回调不重复生成账单；

4. 退费同步流水，金额正负标记清晰；

5. 财务流水无删除、编辑接口；

6. 子公司财务看不到其他分公司收支；

7. 收费规则专项：六种计费模式金额计算准确（固定 / 面积 / 仪表阶梯 / 租金百分比 / 违约金 / 公摊分摊）；批量生成账单幂等（同一摊位同一周期重复请求不重复生成）；历史账单锁定，修改规则后旧账单金额不变；调账记录变更前后金额并强制审计；收费项 / 规则 / 账单跨子公司绑定全部拦截。

### 2\.6 安全专项测试（对齐统一安全开发规范）

1. SQL 注入：所有接口拼接特殊关键字无泄露、报错；

2. XSS 攻击：表单、画布 JSON 脚本前后端双重过滤；

3. 文件上传：exe/html/js 等危险后缀直接拦截；

4. 接口限流：频繁请求登录、导出返回限制提示；

5. 密码、第三方密钥加密存储，接口不返回明文；

6. 生产环境无 SQL 打印、无堆栈报错暴露；

7. 地图批量导出限制权限，防止商户布局数据泄露。

### 2\.7 性能测试标准

1. 单市场 300 \+ 摊位画布加载不卡顿，拖拽流畅；

2. 列表千条数据分页无超时，大数据防抖查询；

3. 页面销毁释放定时器、ECharts、Fabric 实例；

4. 接口并发缴费无脏数据，Redis 缓存正常；

5. 大图前端压缩后上传，加载速度达标。

### 2\.8 审计日志测试

以下操作必须生成完整日志（操作人、company、IP、变更前后 JSON）：

1. 登录 / 密码修改；

2. 权限变更（含二级复核记录）；

3. 地图底图上传、点位保存、地图删除、导出；

4. 缴费、退费、批量核销；

5. 全局参数、UI 主题、第三方密钥修改；

6. 日志不可删除，分公司仅查看自身操作记录。

## 5 缺陷分级与上线阻断规则

1. **阻断级（存在直接禁止上线，必须修复）**

    - 资金交易事务异常、重复扣款；

    - 多租户越权可跨公司查看 / 修改地图 / 财务；

    - 地图点位保存存在注入漏洞；

    - 高危权限无二级复核，单人可删除地图；

    - 收费规则六种计费模式金额计算错误、跨公司绑定摊位生成账单、历史账单被回溯修改；

    2. **严重级（上线限期 24 小时修复）**

    - 画布拖拽 / 点位保存功能失效；

    - 周期账单批量生成重复生成 / 漏生成；

    3. **一般级（可上线迭代修复）**

    - UI 排版、提示文字、导出样式微调；

    4. **优化级（不影响业务，版本迭代）**

    - 交互体验、加载速度小幅优化。
