## 一、整体架构设计（核心规范）

### 1\.1 核心设计原则（强制执行）

- **中台统一封装**：所有上传能力统一封装为 FileUploadService 公共服务，所有业务模块通过依赖注入调用，**禁止业务模块自建上传、校验、存储逻辑**。

- **双模式可无缝切换**：支持 LOCAL 本地磁盘、OSS 对象存储双模式，通过全局配置动态切换，**切换模式无需修改任何业务代码**。

- **动态可配置化**：文件大小、后缀白名单、OSS参数、存储模式等核心参数，通过 sys\_config 表动态管理，支持集团/子公司多租户粒度差异化配置。

- **多层安全兜底**：实现「文件后缀白名单校验\+MIME类型二次校验\+文件名清洗防注入\+危险后缀拦截」四重安全校验，彻底杜绝恶意文件上传风险。

- **全链路可追溯**：所有上传、删除操作均记录数据库日志\+操作审计日志，关联业务模块、业务ID、操作人、操作时间，支持问题溯源与数据复盘。

### 1\.2 系统分层架构（固定结构，禁止改动）

严格遵循项目分层架构，包路径、类名、职责固定，禁止新增冗余类、禁止篡改原有分层逻辑：

### 2\.1 配置文件规范

#### 2\.1\.1 application\.yml 核心业务配置

所有配置支持环境变量注入，适配开发、测试、生产多环境，禁止硬编码配置：

```yaml

    mode: ${UPLOAD_MODE:LOCAL}
    # 本地存储根目录（仅LOCAL模式生效）
    local-base-dir: ${UPLOAD_LOCAL_DIR:D:/upload}
    # 本地文件访问前缀（与静态资源映射保持一致）

    max-file-size: ${UPLOAD_MAX_FILE_SIZE:20971520}
    # 单次请求最大限制50MB（适配批量上传）

    # 图片白名单后缀
    image-extensions: ${UPLOAD_IMAGE_EXT:jpg,jpeg,png,gif,bmp,webp}
    # 通用文件白名单后缀
    file-extensions: ${UPLOAD_FILE_EXT:jpg,jpeg,png,gif,bmp,webp,pdf,doc,docx,xls,xlsx,ppt,pptx,zip,rar,txt,csv}
```

### 2\.2 静态资源映射配置（UploadWebConfig）

仅本地存储模式生效，OSS模式自动失效，配置永久保留，无需删除，保证模式切换兼容性：

```java
package com.gbi.platform.config;

import org.springframework.beans.factory.annotation.Value;
import org.springframework.context.annotation.Configuration;
import org.springframework.web.servlet.config.annotation.ResourceHandlerRegistry;
import org.springframework.web.servlet.config.annotation.WebMvcConfigurer;
import java.nio.file.Paths;

@Configuration
public class UploadWebConfig implements WebMvcConfigurer {

    @Value("${gbi.upload.local-base-dir}")
    private String localBaseDir;

    @Value("${gbi.upload.local-access-prefix:/upload}")
    private String accessPrefix;

    @Override
    public void addResourceHandlers(ResourceHandlerRegistry registry) {
        String absolutePath = Paths.get(localBaseDir).toAbsolutePath().normalize().toString();
        registry.addResourceHandler(accessPrefix + "/**")
                .addResourceLocations("file:" + absolutePath + "/");
    }
}
```

### 2\.7 本地存储实现类规范

通过条件注解仅LOCAL模式生效，实现文件本地存储、目录自动创建、记录入库、物理删除全流程，事务全覆盖：

```java
package com.gbi.platform.service.impl;

import com.gbi.platform.common.constant.UploadConst;
import com.gbi.platform.common.exception.BizException;
import com.gbi.platform.dto.FileUploadDTO;
import com.gbi.platform.entity.SysFileRecord;
import com.gbi.platform.mapper.SysFileRecordMapper;
import com.gbi.platform.service.FileUploadService;
import com.gbi.platform.util.FileUploadUtil;
import com.gbi.platform.vo.FileUploadVO;
import com.gbi.platform.vo.UploadConfigVO;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.boot.autoconfigure.condition.ConditionalOnProperty;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;
import org.springframework.web.multipart.MultipartFile;

import java.io.IOException;
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.Paths;
import java.time.LocalDate;
import java.time.LocalDateTime;
import java.util.ArrayList;
import java.util.List;
import java.util.UUID;

/**
 * 本地文件存储实现
 * 仅gbi.upload.mode=LOCAL时生效
 * @author gbi
 */
@Slf4j
@Service
@RequiredArgsConstructor
@ConditionalOnProperty(name = "gbi.upload.mode", havingValue = "LOCAL", matchIfMissing = true)
public class FileUploadServiceImpl implements FileUploadService {

    @Value("${gbi.upload.local-base-dir:./upload}")
    private String localBaseDir;

    @Value("${gbi.upload.local-access-prefix:/upload}")
    private String accessPrefix;

    private final SysFileRecordMapper fileRecordMapper;

    @Override
    @Transactional(rollbackFor = Exception.class)
    public FileUploadVO upload(MultipartFile file, FileUploadDTO dto) {
        // 1. 多层安全校验
        FileUploadUtil.validateFile(file);

        // 2. 生成唯一文件名
        String originalName = file.getOriginalFilename();
        String ext = FileUploadUtil.getExtension(originalName);
        String storedName = UUID.randomUUID().toString().replace("-", "") + ext;

        // 3. 按业务+日期分层创建目录
        String dateStr = LocalDate.now().toString();
        Path targetDir = Paths.get(localBaseDir, dto.getBizModule(), dateStr);
        try {
            Files.createDirectories(targetDir);
        } catch (IOException e) {
            log.error("本地上传目录创建失败:{}", targetDir, e);
            throw new BizException("上传目录创建失败，请联系管理员");
        }

        // 4. 写入本地文件
        Path targetFile = targetDir.resolve(storedName);
        try {
            file.transferTo(targetFile.toAbsolutePath());
        } catch (IOException e) {
            log.error("本地文件写入失败:{}", originalName, e);
            throw new BizException("文件上传失败，请稍后重试");
        }

        // 5. 构建访问路径
        String relativePath = accessPrefix + "/" + dto.getBizModule() + "/" + dateStr + "/" + storedName;

        // 6. 入库保存文件记录
        SysFileRecord record = new SysFileRecord();
        record.setBizModule(dto.getBizModule());
        record.setOriginalName(originalName);
        record.setStoredName(storedName);
        record.setFilePath(relativePath);
        record.setFileSize(file.getSize());
        record.setMimeType(FileUploadUtil.getMimeType(file));
        record.setExtension(ext);
        record.setFileType(FileUploadUtil.getFileType(ext));
        record.setRefBizId(dto.getRefBizId());
        record.setRemark(dto.getRemark());
        record.setCreateTime(LocalDateTime.now());
        fileRecordMapper.insert(record);

        // 7. 封装返回结果
        FileUploadVO vo = new FileUploadVO();
        vo.setId(record.getId());
        vo.setOriginalName(originalName);
        vo.setStoredName(storedName);
        vo.setFileUrl(relativePath);
        vo.setFilePath(relativePath);
        vo.setFileSize(file.getSize());
        vo.setMimeType(FileUploadUtil.getMimeType(file));
        vo.setExtension(ext);
        vo.setFileType(FileUploadUtil.getFileType(ext));
        vo.setBizModule(dto.getBizModule());
        vo.setRefBizId(dto.getRefBizId());
        vo.setRemark(dto.getRemark());
        vo.setCreateTime(record.getCreateTime());
        return vo;
    }

    @Override
    @Transactional(rollbackFor = Exception.class)
    public List<FileUploadVO> uploadBatch(List<MultipartFile> files, FileUploadDTO dto) {
        List<FileUploadVO> result = new ArrayList<>();
        files.forEach(file -> result.add(upload(file, dto)));
        return result;
    }

    @Override
    @Transactional(rollbackFor = Exception.class)
    public void delete(String fileUrl) {
        if (fileUrl == null || fileUrl.isBlank()) return;
        // 本地物理删除
        try {
            Path targetPath = Paths.get(localBaseDir).resolve(fileUrl.replace(accessPrefix + "/", ""));
            Files.deleteIfExists(targetPath);
            log.info("本地文件物理删除成功:{}", targetPath);
        } catch (IOException e) {
            log.warn("本地文件删除失败，文件可能已不存在:{}", fileUrl, e);
        }
        // 数据库逻辑删除
        fileRecordMapper.deleteByFileUrl(fileUrl);
    }

    @Override
    public String getStorageMode() {
        return UploadConst.STORAGE_MODE_LOCAL;
    }

    @Override
    public UploadConfigVO getUploadConfig() {
        UploadConfigVO vo = new UploadConfigVO();
        vo.setStorageMode(getStorageMode());
        vo.setLocalBaseDir(localBaseDir);
        vo.setAccessPrefix(accessPrefix);
        return vo;
    }
```

### 2\.8 OSS存储实现类规范

仅OSS模式生效，兼容阿里云OSS，支持CDN域名访问，自动处理OSS文件上传、删除、路径拼接：

```java

import com.aliyun.oss.OSS;
import com.aliyun.oss.OSSClientBuilder;
import com.gbi.platform.common.constant.UploadConst;
import com.gbi.platform.common.exception.BizException;

import com.gbi.platform.util.FileUploadUtil;

import com.gbi.platform.vo.UploadConfigVO;

import lombok.extern.slf4j.Slf4j;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.boot.autoconfigure.condition.ConditionalOnProperty;
import org.springframework.stereotype.Service;

import java.time.LocalDate;
import java.time.LocalDateTime;

import java.util.List;

/**
 * OSS对象存储实现
 * 仅gbi.upload.mode=OSS时生效
 * @author gbi

@Slf4j
@Service
@RequiredArgsConstructor
@ConditionalOnProperty(name = "gbi.upload.mode", havingValue = "OSS")
public class OssFileUploadServiceImpl implements FileUploadService {

    @Value("${gbi.oss.endpoint}")
    private String endpoint;
    @Value("${gbi.oss.access-key-id}")
    private String accessKeyId;
    @Value("${gbi.oss.access-key-secret}")
    private String accessKeySecret;
    @Value("${gbi.oss.bucket-name}")
    private String bucketName;
    @Value("${gbi.oss.domain}")
    private String domain;
    @Value("${gbi.oss.path-prefix:gbi-platform/}")

    private final SysFileRecordMapper fileRecordMapper;

     * 构建OSS客户端
     */
    private OSS createOssClient() {
        return new OSSClientBuilder().build(endpoint, accessKeyId, accessKeySecret);

    @Override
    @Transactional(rollbackFor = Exception.class)
    public FileUploadVO upload(MultipartFile file, FileUploadDTO dto) {
        // 1. 安全校验
        FileUploadUtil.validateFile(file);

        // 2. 生成OSS唯一Key
        String originalName = file.getOriginalFilename();
        String ext = FileUploadUtil.getExtension(originalName);
        String dateStr = LocalDate.now().toString();
        String objectKey = pathPrefix + dto.getBizModule() + "/" + dateStr + "/"
                + UUID.randomUUID().toString().replace("-", "") + ext;

        // 3. 上传至OSS
        try (OSS ossClient = createOssClient()) {
            ossClient.putObject(bucketName, objectKey, file.getInputStream(), file.getContentType());
        } catch (IOException e) {
            log.error("OSS文件上传失败:{}", originalName, e);
            throw new BizException("文件上传失败，请稍后重试");
        }

        // 4. 构建完整访问URL（优先CDN域名）
        String fileUrl = domain.isEmpty()
                ? "https://" + bucketName + "." + endpoint + "/" + objectKey
                : domain + "/" + objectKey;

        // 5. 入库记录
        SysFileRecord record = new SysFileRecord();
        record.setBizModule(dto.getBizModule());
        record.setOriginalName(originalName);
        record.setStoredName(objectKey);
        record.setFilePath(objectKey);
        record.setFileSize(file.getSize());
        record.setMimeType(FileUploadUtil.getMimeType(file));
        record.setExtension(ext);
        record.setFileType(FileUploadUtil.getFileType(ext));
        record.setRefBizId(dto.getRefBizId());
        record.setRemark(dto.getRemark());
        record.setCreateTime(LocalDateTime.now());
        fileRecordMapper.insert(record);

        // 6. 封装返回
        FileUploadVO vo = new FileUploadVO();
        vo.setId(record.getId());
        vo.setOriginalName(originalName);
        vo.setStoredName(objectKey);
        vo.setFileUrl(fileUrl);
        vo.setFilePath(objectKey);
        vo.setFileSize(file.getSize());
        vo.setMimeType(FileUploadUtil.getMimeType(file));
        vo.setExtension(ext);
        vo.setFileType(FileUploadUtil.getFileType(ext));
        vo.setBizModule(dto.getBizModule());
        vo.setRefBizId(dto.getRefBizId());
        vo.setRemark(dto.getRemark());
        vo.setCreateTime(record.getCreateTime());
        return vo;
    }

    @Override
    @Transactional(rollbackFor = Exception.class)
    public List<FileUploadVO> uploadBatch(List<MultipartFile> files, FileUploadDTO dto) {
        List<FileUploadVO> result = new ArrayList<>();
        files.forEach(file -> result.add(upload(file, dto)));
        return result;
    }

    @Override
    @Transactional(rollbackFor = Exception.class)
    public void delete(String fileUrl) {
        if (fileUrl == null || fileUrl.isBlank()) return;
        String objectKey = extractObjectKey(fileUrl);
        // OSS物理删除
        try (OSS ossClient = createOssClient()) {
            ossClient.deleteObject(bucketName, objectKey);
            log.info("OSS文件删除成功:{}", objectKey);
        } catch (Exception e) {
            log.warn("OSS文件删除失败，文件可能已不存在:{}", objectKey, e);
        }
        // 数据库逻辑删除
        fileRecordMapper.deleteByFileUrl(fileUrl);
    }

    @Override
    public String getStorageMode() {
        return UploadConst.STORAGE_MODE_OSS;
    }

    @Override
    public UploadConfigVO getUploadConfig() {
        UploadConfigVO vo = new UploadConfigVO();
        vo.setStorageMode(getStorageMode());
        vo.setOssDomain(domain);
        vo.setOssBucket(bucketName);
        return vo;
    }

    /**
     * 从完整URL提取OSS ObjectKey
     */
    private String extractObjectKey(String fileUrl) {
        if (fileUrl.startsWith(domain)) {
            String suffix = fileUrl.substring(domain.length());
            return suffix.startsWith("/") ? suffix.substring(1) : suffix;
        }
        return fileUrl;
    }
```

### 2\.9 上传工具类规范（FileUploadUtil）

统一文件校验、类型识别、文件名清洗工具，所有上传校验逻辑统一收口，禁止分散开发：

```java
package com.gbi.platform.util;

import com.gbi.platform.common.constant.UploadConst;
import com.gbi.platform.common.exception.BizException;
import org.springframework.util.StringUtils;
import org.springframework.web.multipart.MultipartFile;

import java.util.Arrays;
import java.util.HashSet;
import java.util.Set;
import java.util.UUID;

/**
 * 文件上传通用工具类
 * 统一校验、类型识别、文件名处理逻辑
 * @author gbi
 */
public final class FileUploadUtil {

    private static final Set<String> ALLOWED_EXT_SET = new HashSet<>(Arrays.asList(UploadConst.ALLOWED_FILE_EXTENSIONS));
    private static final Set<String> BLOCKED_EXT_SET = new HashSet<>(Arrays.asList(UploadConst.BLOCKED_EXTENSIONS));
    private static final Set<String> IMAGE_EXT_SET = new HashSet<>(Arrays.asList(UploadConst.ALLOWED_IMAGE_EXTENSIONS));

    private FileUploadUtil() {}

    /**
     * 文件全量安全校验（后缀+MIME+文件名防注入）
     */
    public static void validateFile(MultipartFile file) {
        // 空文件校验
        if (file == null || file.isEmpty()) {
            throw new BizException("上传文件不能为空");
        }
        String originalName = file.getOriginalFilename();
        if (!StringUtils.hasText(originalName)) {
            throw new BizException("文件名不能为空");
        }

        // 后缀校验
        String ext = getExtension(originalName).toLowerCase();
        if (ext.isBlank()) {
            throw new BizException("文件后缀不能为空");
        }
        if (!ALLOWED_EXT_SET.contains(ext)) {
            throw new BizException("不支持的文件类型：" + ext + "，允许类型：" + String.join(", ", UploadConst.ALLOWED_FILE_EXTENSIONS));
        }
        if (BLOCKED_EXT_SET.contains(ext)) {
            throw new BizException("禁止上传危险文件类型：" + ext);
        }

        // MIME二次校验（图片强制校验）
        String mimeType = file.getContentType();
        if (!validateMimeType(mimeType, ext)) {
            throw new BizException("文件格式校验失败，请确认文件内容合法");
        }

        // 文件名防路径穿越
        String cleanName = StringUtils.cleanPath(originalName);
        if (cleanName.contains("..") || cleanName.contains("/") || cleanName.contains("\\")) {
            throw new BizException("文件名包含非法字符，禁止上传");
        }
    }

    /**
     * MIME类型校验
     */
    public static boolean validateMimeType(String mimeType, String ext) {
        if (!StringUtils.hasText(mimeType)) return false;
        if (IMAGE_EXT_SET.contains(ext)) {
            String[] imageMimes = {"image/jpeg", "image/png", "image/gif", "image/bmp", "image/webp"};
            return Arrays.asList(imageMimes).contains(mimeType);
        }
        return true;
    }

    /**
     * 获取文件后缀（无点、小写）
     */
    public static String getExtension(String filename) {
        if (filename == null || !filename.contains(".")) return "";
        return filename.substring(filename.lastIndexOf('.') + 1).toLowerCase();
    }

    /**
     * 获取文件MIME类型
     */
    public static String getMimeType(MultipartFile file) {
        String mimeType = file.getContentType();
        return StringUtils.hasText(mimeType) ? mimeType : "application/octet-stream";
    }

    /**
     * 识别文件大类
     */
    public static String getFileType(String ext) {
        if (ext == null) return UploadConst.FILE_TYPE_OTHER;
        String e = ext.toLowerCase();
        if (IMAGE_EXT_SET.contains(e)) return UploadConst.FILE_TYPE_IMAGE;
        if (Arrays.asList("pdf", "doc", "docx", "txt", "csv").contains(e)) return UploadConst.FILE_TYPE_DOC;
        if (Arrays.asList("xls", "xlsx").contains(e)) return UploadConst.FILE_TYPE_EXCEL;
        if (Arrays.asList("zip", "rar", "7z").contains(e)) return UploadConst.FILE_TYPE_ARCHIVE;
        return UploadConst.FILE_TYPE_OTHER;
    }

    /**
     * 生成唯一存储文件名
     */
    public static String generateStoredName(String originalName) {
        String ext = getExtension(originalName);
        return UUID.randomUUID().toString().replace("-", "") + (ext.isBlank() ? "" : "." + ext);
    }
}
```

### 4\.2 全局上传Hook（src/hooks/useUpload\.ts）

封装进度、错误、状态管理，业务页面直接复用，禁止重复开发：

```typescript
import { ref, type Ref } from 'vue'
import { uploadFileApi, uploadBatchApi, type FileUploadVO } from '@/api/base'

interface UseUploadOptions {
  bizModule: string
  refBizId?: number
  maxFileSize?: number
  accept?: string
  onSuccess?: (vo: FileUploadVO) => void
  onBatchSuccess?: (list: FileUploadVO[]) => void
  onError?: (msg: string) => void
}

export function useUpload(options: UseUploadOptions) {
  const uploading = ref(false)
  const error = ref<string | null>(null)
  const result = ref<FileUploadVO | FileUploadVO[] | null>(null)
  const progress = ref(0)

  // 默认最大文件大小20MB
  const defaultMaxSize = options.maxFileSize ?? 20 * 1024 * 1024

  /**
   * 单文件上传
   * @param file 上传文件对象
   */
  async function upload(file: File): Promise<FileUploadVO | undefined> {
    // 重置状态
    uploading.value = true
    error.value = null
    progress.value = 0

    // 文件大小校验
    if (file.size > defaultMaxSize) {
      const errMsg = `文件大小超出限制，最大支持${(defaultMaxSize / 1024 / 1024).toFixed(0)}MB`
      error.value = errMsg
      options.onError?.(errMsg)
      uploading.value = false
      return
    }

    try {
      // 模拟上传进度（适配前端进度展示）
      const progressTimer = setInterval(() => {
        if (progress.value < 90) {
          progress.value += Math.floor(Math.random() * 5)
        }
      }, 100)

      // 调用上传接口
      const res = await uploadFileApi(
        file,
        options.bizModule,
        '',
        options.refBizId
      )

      // 结束进度、赋值结果
      clearInterval(progressTimer)
      progress.value = 100
      result.value = res
      options.onSuccess?.(res)
      return res
    } catch (err: any) {
      const errMsg = err.message || '文件上传失败'
      error.value = errMsg
      options.onError?.(errMsg)
    } finally {
      uploading.value = false
    }
  }

  /**
   * 批量文件上传
   * @param fileList 上传文件列表
   */
  async function uploadBatch(fileList: File[]): Promise<FileUploadVO[] | undefined> {
    uploading.value = true
    error.value = null
    progress.value = 0
    const validFiles = fileList.filter(file => file.size <= defaultMaxSize)

    // 校验是否存在超限文件
    if (validFiles.length !== fileList.length) {
      const errMsg = `部分文件大小超出${(defaultMaxSize / 1024 / 1024).toFixed(0)}MB限制，已过滤`
      error.value = errMsg
      options.onError?.(errMsg)
    }

    if (validFiles.length === 0) {
      uploading.value = false
      return
    }

    try {
      const progressTimer = setInterval(() => {
        if (progress.value < 90) {
          progress.value += Math.floor(Math.random() * 3)
        }
      }, 100)

      const resList = await uploadBatchApi(
        validFiles,
        options.bizModule,
        '',
        options.refBizId
      )

      clearInterval(progressTimer)
      progress.value = 100
      result.value = resList
      options.onBatchSuccess?.(resList)
      return resList
    } catch (err: any) {
      const errMsg = err.message || '批量文件上传失败'
      error.value = errMsg
      options.onError?.(errMsg)
    } finally {
      uploading.value = false
    }
  }

  /**
   * 重置上传状态
   */
  function resetUploadState() {
    uploading.value = false
    error.value = null
    progress.value = 0
    result.value = null
  }

  return {
    uploading,
    error,
    result,
    progress,
    upload,
    uploadBatch,
    resetUploadState
  }
}

```

### 4\.3 前端上传通用规范（强制执行）

所有业务页面上传功能必须遵循以下规则，统一交互、校验、逻辑，禁止自定义零散上传逻辑：

- **统一调用入口**：必须使用封装好的 **uploadFileApi/uploadBatchApi** 接口与**useUpload** 钩子，禁止直接写原生FormData请求、禁止复用旧上传方法。

- **必传业务标识**：上传时必须传入当前业务模块唯一 **bizModule**，关联业务数据需传入 **refBizId**，用于文件分类、数据溯源、权限隔离。

- **前端双重校验**：上传前必须完成前端校验，包含：文件大小校验、文件后缀白名单校验、空文件校验，提前拦截非法文件，减少后端无效请求。

- **交互状态规范**：上传过程必须展示加载进度/loading状态，禁止重复点击上传；上传成功刷新文件列表，上传失败展示精准错误提示。

- **文件删除规范**：业务页面删除附件时，必须调用统一 **deleteFileApi** 接口，同步完成前端列表移除与后端文件、数据删除，禁止仅前端隐藏数据。

- **参数固定规范**：禁止前端硬编码文件大小、文件后缀规则，需通过 **getUploadConfigApi** 动态获取后端配置，保持前后端规则一致。

- **图片预览规范**：所有图片类型附件必须支持在线预览，预览地址直接使用后端返回的 **fileUrl**，禁止拼接自定义路径。

- **批量上传规范**：多文件上传统一走批量接口，禁止循环调用单文件上传接口，减少接口请求次数，提升上传效率。

### 5\.1 后端统一异常枚举

### 5\.2 异常捕获与返回规范

上传全流程异常统一捕获，事务回滚，标准化返回前端，无自定义异常文案：

- 所有上传、删除操作异常，必须触发**事务回滚**，保证数据与文件一致性；

- 禁止直接抛出原生异常信息，必须使用自定义上传异常枚举，返回友好提示；

- 异常发生时，自动记录错误日志，包含文件名、操作人、异常堆栈，便于问题排查；

- 前端统一捕获后端异常码与提示，展示对应错误信息，无需二次翻译。

## 六、安全红线规范（强制禁止）

以下规则为安全红线，所有开发人员必须严格遵守，违规视为代码重大瑕疵，严禁上线：

- **禁止硬编码配置**：OSS密钥、路径、文件大小、后缀白名单禁止硬编码，必须通过配置文件\+环境变量\+数据库配置动态管理。

- **禁止绕过校验**：禁止删除、屏蔽四重安全校验（后缀白名单、MIME校验、文件名清洗、黑名单拦截）。

- **禁止自定义上传接口**：所有业务上传必须走统一UploadController入口，禁止新增独立上传接口。

- **禁止存储高危文件**：严禁可执行文件、脚本文件、网页文件上传，黑名单永久生效，禁止私自修改。

- **禁止文件路径暴露**：禁止前端直接传递文件存储路径，所有路径由后端统一生成、管控。

- **禁止物理删除业务数据**：文件记录仅允许逻辑删除，物理文件可清理，数据库数据永久留存溯源。

- **禁止无权限上传**：所有上传、删除操作必须携带权限校验，禁止放开匿名上传权限。

## 七、代码复用与迭代规范

### 7\.1 复用规则

- 全系统所有上传场景**100%复用公共FileUploadService能力**，零自定义上传逻辑。

- 校验、文件名处理、类型识别统一复用FileUploadUtil，禁止重复编写工具方法。

- 前端统一复用useUpload钩子与上传API，业务页面仅传业务参数，无需关注底层上传逻辑。

### 7\.2 迭代拓展规则

- 新增文件类型：仅需修改UploadConst白名单\+数据库默认配置，无需改动业务代码。

- 新增存储模式：仅需新增FileUploadService实现类，不修改原有业务、前端代码。

- 新增校验规则：统一在FileUploadUtil收拢拓展，全链路生效。

- 配置迭代：所有可配置参数通过sys\_config表动态拓展，支持多租户差异化配置。

## 八、落地校验与验收标准

### 8\.1 开发自测标准

- 双存储模式切换测试：LOCAL/OSS模式切换，业务无报错、文件正常上传访问。

- 安全校验测试：高危后缀、超限文件、非法文件名均能被正常拦截。

- 事务一致性测试：上传异常时，无残留文件、无脏数据。

- 权限测试：无权限用户无法执行上传、删除操作。

- 日志溯源测试：所有上传、删除操作正常生成审计日志与数据库记录。

### 8\.2 代码验收标准

- 无自定义上传、校验、存储逻辑，完全依赖公共服务。

- 配置无硬编码，隐私参数通过环境变量注入。

- 文件记录完整，字段齐全，索引有效。

- 前后端规则统一，无校验差异。

- 无安全红线违规问题，异常处理完善。
