> 文档版本：v2.1（完整版）

> 定位：规范考勤同步打卡的完整逻辑，支持多休息日类型、法定节假日、特殊岗位排班、免考勤员工、班次管理、异常检测提醒、报表生成

## 一、业务需求

### 1.1 当前问题

| 问题 | 影响 |
|------|------|
| 周末天数不固定（单休/双休） | 应出勤天数计算错误 |
| 无法定节假日处理 | 节假日被计入工作日或休息日 |
| 特殊岗位无排班规则 | 轮班制员工考勤无法正确统计 |
| 同步逻辑简单粗暴 | 只同步有打卡的日期，不生成缺卡记录 |
| 无免考勤员工处理 | 销售、高管等人员无法正常处理考勤 |
| 新员工/离职员工处理不当 | 当月入职/离职日期未考虑 |
| 历史数据无法回溯 | 配置修改后无法重新同步历史月份 |
| 缺少审计日志 | 同步操作无追溯记录 |

### 1.2 目标

1. 支持多种休息日类型配置（单休、双休、做五休二、做六休一、综合工时）
2. 支持法定节假日自动排除
3. 支持特殊岗位/员工的个性化排班
4. 同步时自动生成"缺卡"记录（工作日无打卡）
5. 同步前预览结果，确认后执行
6. **支持免考勤员工**：部分员工不参与考勤，同步时默认为满勤
7. **支持入职/离职日期处理**：当月入职/离职员工按实际在职天数计算
8. **支持历史数据回溯**：配置修改后可重新同步历史月份
9. **配置参数化管理**：关键阈值参数写入sys_config表，支持动态调整
10. **完整审计日志**：同步操作记录操作人、时间、变更内容

## 三、工作日计算逻辑

### 3.1 优先级顺序

```
1. hr_employee.exempt_attendance == 1 → 免考勤，直接返回满勤
2. hr_employee.special_schedule（员工个人特殊排班）
3. hr_employee.workweek_config_id（员工个人配置）
4. hr_post.workweek_config_id（岗位默认配置）
5. sys_org.default_workweek_config_id（组织默认配置）
6. sys_workweek_config（公司级默认配置，默认双休）
```

### 3.2 工作日判定伪代码

```java
/**
 * 判断某日期是否为工作日
 */
public boolean isWorkDay(LocalDate date, Long employeeId, Long companyId) {
    // 0. 检查是否免考勤
    HrEmployee employee = employeeMapper.selectById(employeeId);
    if (employee.getExemptAttendance() != null && employee.getExemptAttendance() == 1) {
        return true; // 免考勤员工的所有日期都视为工作日（用于生成满勤记录）
    }
    
    // 1. 检查员工特殊排班
    if (employee.getSpecialSchedule() != null) {
        String schedule = employee.getSpecialSchedule().get(date.toString());
        if ("上班".equals(schedule)) return true;
        if ("休息".equals(schedule)) return false;
    }
    
    // 2. 检查法定节假日
    SysHolidayConfig holiday = holidayMapper.selectByDate(date, companyId);
    if (holiday != null) {
        return holiday.getIsWorkday() == 1;
    }
    
    // 3. 获取休息日配置
    Integer workweekType = getWorkweekType(employee, companyId);
    
    // 4. 根据workweekType判断
    DayOfWeek dow = date.getDayOfWeek();
    switch (workweekType) {
        case 1: // 单休 - 周日休息
            return dow != DayOfWeek.SUNDAY;
        case 2: // 双休 - 周六日休息
            return dow != DayOfWeek.SATURDAY && dow != DayOfWeek.SUNDAY;
        case 3: // 做五休二 - 周五六休息
            return dow != DayOfWeek.FRIDAY && dow != DayOfWeek.SATURDAY;
        case 4: // 做六休一 - 周日休息
            return dow != DayOfWeek.SUNDAY;
        case 5: // 综合工时 - 需人工确认
            return false; // 由管理员手动标记
        default:
            return dow != DayOfWeek.SATURDAY && dow != DayOfWeek.SUNDAY; // 默认双休
    }
}
```

### 3.3 月度工作日计算（含入职离职处理）

```java
/**
 * 计算当月工作日列表（考虑员工入职/离职日期）
 */
public List<LocalDate> calcWorkDays(String attendanceMonth, Long employeeId) {
    LoginUser loginUser = UserContext.getLoginUser();
    HrEmployee employee = employeeMapper.selectById(employeeId);
    
    LocalDate monthStart = LocalDate.parse(attendanceMonth + "-01");
    LocalDate monthEnd = monthStart.plusMonths(1).minusDays(1);
    
    // 处理入职日期：当月入职的，从入职日开始计算
    if (employee.getEntryDate() != null && employee.getEntryDate().isAfter(monthStart)) {
        monthStart = employee.getEntryDate();
    }
    
    // 处理离职日期：当月离职的，到离职日为止
    if (employee.getResignDate() != null && employee.getResignDate().isBefore(monthEnd)) {
        monthEnd = employee.getResignDate();
    }
    
    List<LocalDate> workDays = new ArrayList<>();
    LocalDate current = monthStart;
    
    while (!current.isAfter(monthEnd)) {
        if (isWorkDay(current, employeeId, loginUser.getCompanyId())) {
            workDays.add(current);
        }
        current = current.plusDays(1);
    }
    
    return workDays;
}
```

### 4.2 同步执行逻辑

```java
@Override
@Transactional
public int syncMonthly(String attendanceMonth, Long employeeId) {
    LoginUser loginUser = UserContext.getLoginUser();
    LocalDate monthStart = LocalDate.parse(attendanceMonth + "-01");
    LocalDate monthEnd = monthStart.plusMonths(1).minusDays(1);
    
    // 1. 获取目标员工列表
    List<HrEmployee> employees = getTargetEmployees(employeeId, loginUser.getCompanyId());
    
    // 2. 计算当月工作日
    List<LocalDate> workDays = calcWorkDaysForMonth(monthStart, monthEnd, loginUser.getCompanyId());
    
    // 3. 获取考勤配置参数
    int lateThreshold = getConfigInt("attendance.late_threshold", 30);
    int absentThreshold = getConfigInt("attendance.absent_threshold", 480);
    int earlyThreshold = getConfigInt("attendance.early_threshold", 30);
    
    int totalCount = 0;
    int fullAttendanceCount = 0;
    int normalCount = 0;
    int lateCount = 0;
    int absentCount = 0;
    
    for (HrEmployee employee : employees) {
        // 4. 检查是否免考勤
        if (employee.getExemptAttendance() != null && employee.getExemptAttendance() == 1) {
            // 免考勤员工：所有工作日默认为满勤
            for (LocalDate workDay : workDays) {
                upsertAttendanceRecord(employee, attendanceMonth, workDay, 
                    null, null, 1, 0, loginUser.getUserId());
                fullAttendanceCount++;
            }
            log.info("employee {} is exempt from attendance, set full attendance for {} days", 
                     employee.getName(), workDays.size());
            continue;
        }
        
        // 5. 查询该员工当月OA打卡记录
        List<OaClockRecord> clockRecords = queryClockRecords(
            employee.getUserId(), monthStart, monthEnd, loginUser.getCompanyId()
        );
        
        // 6. 按日期聚合打卡记录
        Map<LocalDate, ClockPair> dayMap = aggregateByDate(clockRecords);
        
        // 7. 生成考勤记录
        for (LocalDate workDay : workDays) {
            ClockPair pair = dayMap.get(workDay);
            Integer clockType;
            Integer lateMinutes = 0;
            
            if (pair != null) {
                // 有打卡记录
                clockType = calculateClockType(pair, lateThreshold, absentThreshold, earlyThreshold);
                lateMinutes = calculateLateMinutes(pair, lateThreshold);
                if (clockType == 1) normalCount++;
                else if (clockType == 2) lateCount++;
            } else {
                // 无打卡记录 → 生成缺卡
                clockType = 4;
                absentCount++;
            }
            
            upsertAttendanceRecord(employee, attendanceMonth, workDay,
                pair != null ? pair.getClockInTime() : null,
                pair != null ? pair.getClockOutTime() : null,
                clockType, lateMinutes, loginUser.getUserId());
            totalCount++;
        }
    }
    
    // 8. 记录审计日志
    auditLogUtil.record("ATTENDANCE_SYNC", loginUser.getUserId(), 
        String.format("同步考勤月份=%s, 总记录=%d, 满勤=%d, 正常=%d, 迟到=%d, 缺卡=%d",
            attendanceMonth, totalCount, fullAttendanceCount, normalCount, lateCount, absentCount));
    
    log.info("attendance sync done: month={}, employeeCount={}, totalRecords={}, fullAttendance={}, normal={}, late={}, absent={}", 
             attendanceMonth, employees.size(), totalCount, fullAttendanceCount, normalCount, lateCount, absentCount);
    
    // 9. 检测考勤异常
    detectAttendanceExceptions(attendanceMonth, loginUser.getCompanyId());
    
    return totalCount;
}

/**
 * 检测考勤异常
 */
private void detectAttendanceExceptions(String attendanceMonth, Long companyId) {
    LocalDate monthStart = LocalDate.parse(attendanceMonth + "-01");
    LocalDate monthEnd = monthStart.plusMonths(1).minusDays(1);
    int absentThreshold = getConfigInt("attendance.absent_reminder_threshold", 3);
    int lateFrequentThreshold = getConfigInt("attendance.late_frequent_threshold", 5);
    boolean reminderEnabled = getConfigInt("attendance.reminder_enabled", 1) == 1;
    
    // 1. 检测连续缺卡
    List<Long> absentEmployees = attendanceRecordMapper.selectAbsentEmployees(companyId, monthStart, monthEnd, absentThreshold);
    for (Long employeeId : absentEmployees) {
        createExceptionRecord(companyId, employeeId, 1, monthStart, "连续缺卡");
    }
    
    // 2. 检测月度迟到频繁
    List<Long> lateEmployees = attendanceRecordMapper.selectLateFrequentEmployees(companyId, monthStart, monthEnd, lateFrequentThreshold);
    for (Long employeeId : lateEmployees) {
        createExceptionRecord(companyId, employeeId, 2, monthStart, "月度迟到频繁");
    }
    
    // 3. 检测旷工
    List<Long> absentEmployees2 = attendanceRecordMapper.selectAbsentEmployees(companyId, monthStart, monthEnd, 0);
    for (Long employeeId : absentEmployees2) {
        createExceptionRecord(companyId, employeeId, 3, monthStart, "旷工");
    }
    
    // 4. 发送异常提醒
    if (reminderEnabled) {
        sendExceptionReminders(companyId, monthStart);
    }
}

/**
 * 计算打卡类型（含旷工判断）
 */
private Integer calculateClockType(ClockPair pair, int lateThreshold, int absentThreshold, int earlyThreshold) {
    LocalTime clockIn = pair.getClockInTime().toLocalTime();
    LocalTime clockOut = pair.getClockOutTime().toLocalTime();
    
    // 计算迟到分钟数
    long lateMinutes = calculateLateMinutesInternal(clockIn, lateThreshold);
    
    // 迟到超过阈值认定为迟到，超过旷工阈值认定为旷工
    if (lateMinutes >= absentThreshold) {
        return 5; // 旷工
    }
    if (lateMinutes > 0) {
        return 2; // 迟到
    }
    
    // 早退判断
    long earlyMinutes = calculateEarlyMinutesInternal(clockOut, earlyThreshold);
    if (earlyMinutes > 0) {
        return 3; // 早退
    }
    
    return 1; // 正常
}

```java
/**
 * 计算打卡类型（支持多班次）
 */
private Integer calculateClockType(ClockPair pair, HrEmployee employee, LocalDate workDay,
        int lateThreshold, int absentThreshold, int earlyThreshold) {
    LocalTime clockIn = pair.getClockInTime().toLocalTime();
    LocalTime clockOut = pair.getClockOutTime().toLocalTime();
    
    // 1. 获取员工当日班次
    ShiftConfig shift = getEmployeeShift(employee.getId(), workDay);
    LocalTime shiftStart = shift.getStartTime();
    LocalTime shiftEnd = shift.getEndTime();
    
    // 2. 计算迟到分钟数（相对于班次上班时间）
    long lateMinutes = 0;
    if (clockIn.isAfter(shiftStart)) {
        lateMinutes = java.time.Duration.between(shiftStart, clockIn).toMinutes();
    }
    
    // 3. 判断是否旷工
    if (lateMinutes >= absentThreshold) {
        return 5; // 旷工
    }
    
    // 4. 判断是否迟到
    if (lateMinutes > lateThreshold) {
        return 2; // 迟到
    }
    
    // 5. 计算早退分钟数（相对于班次下班时间）
    long earlyMinutes = 0;
    if (!clockOut.isAfter(shiftEnd)) {
        earlyMinutes = java.time.Duration.between(clockOut, shiftEnd).toMinutes();
    }
    
    // 6. 判断是否早退
    if (earlyMinutes > earlyThreshold) {
        return 3; // 早退
    }
    
    return 1; // 正常
}

/**
 * 获取员工当日班次配置
 */
private ShiftConfig getEmployeeShift(Long employeeId, LocalDate date) {
    // 1. 查询员工班次配置（按日期范围匹配）
    List<HrEmployeeShift> shifts = shiftMapper.selectList(
        new LambdaQueryWrapper<HrEmployeeShift>()
            .eq(HrEmployeeShift::getEmployeeId, employeeId)
            .eq(HrEmployeeShift::getStatus, 1)
            .le(HrEmployeeShift::getStartDate, date)
            .and(w -> w.isNull(HrEmployeeShift::getEndDate)
                      .or().ge(HrEmployeeShift::getEndDate, date))
    );
    
    if (!shifts.isEmpty()) {
        HrEmployeeShift shift = shifts.get(0);
        return new ShiftConfig(shift.getShiftType(), shift.getShiftStartTime(), shift.getShiftEndTime());
    }
    
    // 2. 查询岗位默认班次
    HrEmployee employee = employeeMapper.selectById(employeeId);
    if (employee.getPostId() != null) {
        HrPost post = postMapper.selectById(employee.getPostId());
        if (post.getShiftType() != null) {
            return getShiftConfigByType(post.getShiftType());
        }
    }
    
    // 3. 默认标准工时
    return getShiftConfigByType(1);
}

/**
 * 根据班次类型获取时间配置
 */
private ShiftConfig getShiftConfigByType(Integer shiftType) {
    switch (shiftType) {
        case 2: // 早班
            return new ShiftConfig(2,
                LocalTime.parse(getConfig("attendance.shift_morning_start", "08:00")),
                LocalTime.parse(getConfig("attendance.shift_morning_end", "17:00")));
        case 3: // 晚班
            return new ShiftConfig(3,
                LocalTime.parse(getConfig("attendance.shift_evening_start", "14:00")),
                LocalTime.parse(getConfig("attendance.shift_evening_end", "23:00")));
        case 4: // 夜班
            return new ShiftConfig(4,
                LocalTime.parse(getConfig("attendance.shift_night_start", "22:00")),
                LocalTime.parse(getConfig("attendance.shift_night_end", "07:00")));
        default: // 标准工时
            return new ShiftConfig(1,
                LocalTime.parse(getConfig("attendance.normal_clockin_start", "08:30")),
                LocalTime.parse(getConfig("attendance.normal_clockout_end", "18:30")));
    }
}

## 九、部署注意事项

1. **升级顺序**：先执行SQL → 重启后端 → 配置休息日/节假日 → 测试同步
2. **存量数据处理**：已有考勤记录不受影响，新同步会覆盖
3. **首次使用**：建议先用一个子公司试运行，确认工作日计算正确后再全量
4. **节假日更新**：每年12月更新次年法定节假日配置
5. **参数调整**：考勤参数修改后立即生效，无需重启服务
6. **重新同步**：支持按月份重新同步，建议选择"重新同步"模式覆盖旧数据
