## 二、核心流程

```
HR 填写入职申请（含完整员工信息：身份证/手机/性别/出生日期/组织/岗位/工资/银行卡）
         ↓
  提交 → 工号唯一性校验（排除草稿/审批中记录）→ 进入审批流
         ↓
   审批通过 → HrEntryFlowHandler.onPass()
         ↓
   HrTransferService.onEntryApproved()
         ↓
   更新 hr_entry_apply.status = 2（已通过）
         ↓
   HrEmployeeService.createFromEntry()
         ↓
   查重后插入 hr_employee（status=1 在职）+ 审计日志
         ↓
   审批驳回 → onEntryRejected() → status=3（已驳回），不建档
   撤销申请 → status=4（已撤回），不建档
```

## 五、风险与注意事项

1. **循环依赖**：`HrTransferServiceImpl` 注入 `HrEmployeeService`，`HrEmployeeServiceImpl` 注入 `HrEntryApplyMapper`，同层无循环，安全
2. **并发重复建档**：`hr_employee` 表已有 `(company_id, employee_no)` 约束作为最后防线（待确认）
3. **历史数据兼容**：执行 SQL 前建议先查询是否有重复工号数据
4. **`CommonConst` 未添加 `EMPLOYEE_STATUS_REGULAR`**：使用字面量 `2` 替代，保持常量类稳定
