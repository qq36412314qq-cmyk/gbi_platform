## 一、加班申请

### 1.1 入口
人力资源 → 加班管理 → 加班申请（路径：`/hr/overtime/apply`）

### 1.2 状态流转图
```
提交申请 (status=0 待审批)
    │
    ├─── 申请人撤回 ───→ status=3 已撤回
    │
    ├─── 审批通过 ─────→ status=1 已通过 ──→ 自动生成加班记录
    │
    └─── 审批驳回 ─────→ status=2 已驳回
```

### 1.3 操作步骤

#### ① 新增加班申请
**权限**：`hr:overtime:apply:add`

1. 点击「新增加班申请」按钮，弹出表单
2. 填写以下字段：
   - **员工**：从下拉列表选择（支持搜索）
   - **加班日期**：选择日期
   - **时段**：开始时间 ~ 结束时间（必填，自动计算预计时长）
   - **预计时长**：小时数（支持 0.5 递增）
   - **加班类型**：工作日 / 休息日 / 法定节假日（留空按日期自动判断）
   - **加班事由**：必填，最多 500 字
3. 点击「确定」提交，系统自动发起审批流程
4. 提交后状态变为「待审批」

#### ② 编辑加班申请
**权限**：`hr:overtime:apply:edit`

- 仅 **status=0（待审批）** 的申请可编辑
- 点击列表中对应行的「编辑」按钮
- 修改完成后点击「确定」保存

#### ③ 撤回加班申请
**权限**：`hr:overtime:apply:revoke`

- 仅 **status=0（待审批）** 的申请可撤回
- 点击对应行的「撤回」按钮，确认后状态变为「已撤回」
- 撤回后对应的流程实例同步终止

#### ④ 删除加班申请
**权限**：`hr:overtime:apply:delete`

- 仅 **status=0（待审批）** 的申请可删除
- 点击对应行的「删除」按钮，二次确认后物理删除记录

## 二、加班记录

### 2.1 入口
人力资源 → 加班管理 → 加班记录（路径：`/hr/overtime/record`）

### 2.2 字段含义
- **来源类型**：`1=手动申请`（由审批通过的申请转化）、`2=自动识别`（由系统根据考勤打卡记录推算）
- **确认状态**：`0=待确认`、`1=已确认`、`2=已驳回`
- **状态**：`1=有效`、`2=已抵扣`（已用于调休）、`3=已作废`
- **补偿状态**：`0=未补偿`、`1=已调休`、`2=已发放加班费`

### 2.3 操作步骤

#### ① 触发自动识别
**权限**：`hr:overtime:record:detect`

1. 点击「触发自动识别（昨日）」按钮
2. 系统根据昨日考勤打卡记录，识别符合条件的加班（超出正常工时的部分）
3. 识别结果展示：总记录数、新增数、更新数、跳过数
4. 识别产生的记录默认为「待确认」状态

> **前置条件**：需在「加班配置」中启用「自动识别」功能，并确保员工已完成打卡

#### ② 确认/驳回加班记录
**权限**：`hr:overtime:record:confirm` / `hr:overtime:record:reject`

- **确认**：适用于 `confirm_status=0（待确认）` 的记录
  - 点击「确认」按钮，记录状态变为「有效（status=1）」
  - 确认后可进入补偿台账
- **驳回**：
  - 点击「驳回」按钮，弹出驳回原因输入框
  - 确认后记录状态变为「已作废（status=3）」

#### ③ 导出加班记录
**权限**：`hr:overtime:record:export`

- 点击「导出」按钮，按当前筛选条件导出 Excel

## 三、加班补偿

### 3.1 入口
人力资源 → 加班管理 → 加班补偿（路径：`/hr/overtime/compensate`）

### 3.2 台账字段说明
| 字段 | 含义 |
|------|------|
| 基准月薪 | 员工当前薪资档案中的基本工资 |
| 累计加班时长 | 当月所有有效记录的加班总时长 |
| 工作日/休息日/法定时长 | 按加班类型分类统计的时长 |
| 已用时 | 已调休使用的时长 |
| 剩余可使用时长 | 累计时长 - 已用时 |
| 加班费金额 | 根据配置倍率计算的应付加班费 |
| 发放状态 | 0=待发放 / 1=已发放 / 2=已取消 |

### 3.3 操作步骤

#### ① 核算当月补偿
**权限**：`hr:overtime:compensate:calculate`

1. 点击「核算当月补偿」按钮
2. 选择核算月份（默认当前月）
3. 点击「确定」，系统：
   - 汇总该月所有 `confirm_status=1` 的加班记录
   - 按配置的倍率（工作日1.5x / 休息日2x / 法定3x）计算加班费
   - 生成或更新 `hr_overtime_compensate` 台账记录
4. 核算完成后，台账显示各员工的加班时长和应付加班费

> **注意**：需先在「加班配置」中配置好各类型加班倍率和补偿优先级

#### ② 发放加班费
**权限**：`hr:overtime:compensate:pay`

- 仅 **pay_status=0（待发放）** 的记录可发放
- 点击「发放」按钮，二次确认后状态变为「已发放」
- 发放后该笔金额将同步至当月薪资（需在生成薪资时勾选「同步加班费」）

#### ③ 导出补偿明细
**权限**：`hr:overtime:compensate:export`

- 点击「导出补偿明细」按钮，按当前筛选条件导出 Excel

## 四、加班配置

### 4.1 入口
人力资源 → 加班管理 → 加班配置（路径：`/hr/overtime/config`）

### 4.2 配置项说明
| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| 配置名称 | 该套配置的业务标识 | 集团加班通用配置 |
| 最小加班时长 | 计入加班的最短时间（小时） | 0.5 |
| 取整模式 | 时长记录取整方式（向上/四舍五入/向下） | 向上取整 |
| 工作日加班倍率 | 工作日加班费计算倍率 | 1.5 |
| 休息日加班倍率 | 休息日加班费计算倍率 | 2.0 |
| 法定节假日倍率 | 法定节假日加班费计算倍率 | 3.0 |
| 每月最大加班时长上限 | 月加班上限（0=不限） | 0 |
| 补偿优先级 | 优先调休 / 优先加班费 / 混合 | 调休优先 |
| 自动识别 | 是否启用考勤自动识别加班 | 关闭 |

### 4.3 操作步骤

#### ① 保存配置
**权限**：`hr:overtime:config:save`

1. 进入「加班配置」页面，当前公司配置自动加载
2. 修改需要调整的参数
3. 点击「保存配置」按钮，写入 `sys_overtime_config` 表

#### ② 启用/禁用配置
**权限**：`hr:overtime:config:status`

- 启用：自动识别和补偿核算功能生效
- 禁用：系统不再自动处理加班数据
- 切换开关即时生效，无需重新保存

## 五、权限分配说明

### 5.1 菜单结构
```
人力资源（parent_id=107）
└── 加班管理（id=242，目录）
    ├── 加班申请（id=243）
    ├── 加班记录（id=244）
    ├── 加班补偿（id=245）
    └── 加班配置（id=246）
```

### 5.2 按钮权限与角色建议
| 权限标识 | 操作 | 建议授予 |
|----------|------|----------|
| `hr:overtime:apply:add` | 新增加班申请 | 全员 |
| `hr:overtime:apply:edit` | 编辑加班申请 | 申请人本人 |
| `hr:overtime:apply:delete` | 删除加班申请 | 子公司经理及以上 |
| `hr:overtime:apply:revoke` | 撤回加班申请 | 申请人本人 |
| `hr:overtime:record:detect` | 触发自动识别 | 子公司经理及以上 |
| `hr:overtime:record:confirm` | 确认加班记录 | 子公司经理及以上 |
| `hr:overtime:record:reject` | 驳回加班记录 | 子公司经理及以上 |
| `hr:overtime:record:export` | 导出加班记录 | 子公司经理及以上 |
| `hr:overtime:compensate:calculate` | 核算加班补偿 | 子公司经理及以上 |
| `hr:overtime:compensate:pay` | 发放加班费 | 集团管理员 |
| `hr:overtime:compensate:export` | 导出补偿明细 | 子公司经理及以上 |
| `hr:overtime:config:save` | 保存配置 | 集团管理员 |
| `hr:overtime:config:status` | 启用/禁用 | 集团管理员 |

### 5.3 审批流说明
- **流程定义**：`hr_overtime_apply`，单节点（直属主管审批）
- **审批通过**：`HrOvertimeApplyFlowHandler.onPass` → 更新 `status=1`
- **审批驳回**：`HrOvertimeApplyFlowHandler.onReject` → 更新 `status=2`

## 六、与薪资模块联动

### 6.1 数据流向
```
加班记录（已确认） → 加班补偿台账 → 生成薪资时同步 → 月度薪资核算
```

### 6.2 联动操作步骤
1. 在「加班补偿」页面完成当月补偿核算，并确认加班费金额正确
2. 如需要发放，点击「发放」按钮标记为已发放
3. 进入「薪资管理 → 月度薪资」页面
4. 点击「生成薪资」，弹窗中勾选「同步加班费」
5. 系统按 `compensateMonth = salaryMonth` 聚合 `hr_overtime_compensate.overtimeAmount`
6. 加班费写入 `hr_salary_month.overtime_amount`，并重新计算实发金额（netAmount）

## 七、常见问题

| 问题 | 原因 | 解决方式 |
|------|------|----------|
| 审批通过后申请仍显示「待审批」 | 缺少 FlowBizHandler 处理器 | 已修复（HrOvertimeApplyFlowHandler），重启服务生效 |
| 自动识别无数据 | 未启用自动识别或考勤数据不足 | 在「加班配置」中启用自动识别，确认员工已打卡 |
| 补偿金额为 0 | 核算前无已确认的加班记录 | 先完成加班记录确认，再执行核算 |
| 生成薪资后无加班费 | 未勾选「同步加班费」 | 生成薪资时开启同步开关 |
| 导出接口报错 | 后端导出功能待实现 | Phase 7 接入 hutool ExcelUtil 后修复 |
