# 考勤配置管理页面修复说明

## 问题诊断
考勤配置管理页面列表空白，原因是：
1. 前端调用的API方法不存在
2. 后端缺少对应的Controller端点
3. 后端Service缺少实现方法

## 已完成的修复

### 1. 前端API层 (`src/api/hr.ts`)
- 新增 `getWorkweekConfigListApi()` - 查询休息日配置列表
- 新增 `createWorkweekConfigApi()` - 新增休息日配置
- 新增 `getHolidayConfigListApi()` - 查询节假日配置列表
- 新增 `createHolidayConfigApi()` - 新增节假日配置

### 2. 后端Controller层 (`AttendanceController.java`)
- 新增 `GET /hr/attendance/workweek/list` - 查询休息日配置列表
- 新增 `GET /hr/attendance/holiday/list` - 查询节假日配置列表
- 保留原有分页接口 `GET /hr/attendance/workweek/page`
- 保留原有分页接口 `GET /hr/attendance/holiday/page`

### 3. 后端Service层
- 接口 `HrAttendanceService.java` 新增：
  - `listWorkweekConfigs()` - 查询休息日配置列表
  - `listHolidayConfigs(Integer year)` - 查询节假日配置列表

- 实现类 `HrAttendanceServiceImpl.java` 新增：
  - `listWorkweekConfigs()` - 实现查询逻辑，按状态过滤、排序
  - `listHolidayConfigs(Integer year)` - 实现查询逻辑，按年份过滤
