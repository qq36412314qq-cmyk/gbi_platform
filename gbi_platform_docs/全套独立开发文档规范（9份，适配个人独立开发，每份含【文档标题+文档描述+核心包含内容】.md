# 全套独立开发文档规范（9份，适配个人独立开发，每份含【文档标题\+文档描述\+核心包含内容】

## 1、工程基础规范

**文档描述**：统一前后端、小程序工程目录结构、多环境配置、打包发布、回滚方案、系统中台公共能力（流程引擎 / 消息中心 / 文件存储 / 全局工具）标准，个人开发统一工程写法，避免环境混乱、公共逻辑重复编写。
核心包含：

1. 后端 SpringBoot 标准分层目录；

2. Vue3 PC 后台 \+ 商户小程序前端目录；

3. 开发 / 测试 / 生产多环境配置区分；

4. 项目打包、发布、数据库备份、故障回滚流程；

5. 统一中台公共能力：流程引擎、消息通知、OSS 文件、全局导入导出、打印公共组件开发约束。

## 2、后端编码规范

**文档描述**：Java SpringBoot 统一编码标准，涵盖命名、注释、分层代码写法、事务、定时任务、异常处理、工具类开发规则，单人开发统一代码风格，便于长期迭代维护。
核心包含：

1. 包、类、方法、变量、常量命名规则；

2. Controller/Service/Mapper/DTO/VO 分层编码约束；

3. 事务使用规范、定时任务开发标准；

4. 统一异常捕获、全局异常处理器；

5. 工具类、枚举、字典编码要求；

6. 业务代码轻量化开发准则（个人独立开发精简冗余逻辑）。

## 3、数据库设计规范

**文档描述**：MySQL 统一建表、字段、索引、多租户隔离标准，约束所有业务表统一字段、命名、存储规则，适配集团多子公司`company_id`数据隔离，防止建表混乱、字段不统一。
核心包含：

1. 库、表、字段、索引命名规范；

2. 每张表强制通用字段（id、company\_id、create\_by、create\_time、update\_by、update\_time、is\_delete）；

3. 字段类型、长度、非空、默认值约束；

4. 多租户数据隔离设计规则；

5. 新增 market\_map 摊位地图、人事、营销全套表设计标准；

6. SQL 编写、联表查询、分页查询限制规范。

## 4、API \& 日志规范

**文档描述**：合并接口统一标准 \+ 日志双规范，定义前后端交互请求 / 返回格式、统一错误码、分页规则；区分系统调试日志与业务审计日志，日志打印、脱敏、存储统一标准，方便排查问题与合规审计。
核心包含：

1. 全局统一接口返回结构体；

2. 分页、排序、筛选、文件上传下载接口规范；

3. 全局错误码定义（业务 / 系统 / 权限 / 第三方）；

4. 接口入参校验统一标准；

5. 调试日志：打印级别、敏感信息屏蔽；

6. 审计日志：操作记录存储范围（权限变更、地图操作、财务、删除等高风险动作）；

7. 日志持久化与查询规范。

## 5、前端页面开发规范

**文档描述**：Vue3 \+ Vite \+ Element Plus PC 后台、微信小程序全套前端开发标准，包含目录、命名、组件、表单表格、简约扁平化 UI、主题自定义、Fabric 摊位地图画布、交互、性能、安全全部约束，即你现有完整前端规范文档。
核心包含：

1. 前端目录、文件、CSS 命名规则；

2. 通用 / 业务组件开发规范；

3. 表单、列表、弹窗、打印导出统一模板；

4. 2026 简约扁平化 UI 设计、全局 CSS 变量主题配置规范；

5. Fabric\.js 摊位可视化画布开发标准；

6. 页面性能、交互、前端安全、商户小程序规范。

## 6、权限 \& 多租户隔离规范

**文档描述**：集团多业态系统专属规范，定义 RBAC 角色权限、菜单配置、集团 / 子公司数据隔离、分级权限二级审核机制、前端权限按钮控制，统一全系统数据过滤、权限校验逻辑，杜绝越权、数据跨公司泄露。
核心包含：

1. 集团独有 / 子公司独有 / 全共享模块划分规则；

2. 前后端权限标识 permission 编码规范；

3. 菜单导航树设计标准；

4. company\_id 全局数据过滤规则；

5. 敏感权限二级双人审核完整流程；

6. 审计日志权限变更记录规范；

7. 前端 AuthBtn 权限组件使用标准。

## 7、第三方集成规范

**文档描述**：统一所有外部系统对接开发标准，包含钉钉考勤、金蝶财务、OSS 存储、商户小程序、Fabric 画布前后端交互、UI 主题联动，规范鉴权、重试、幂等、异常处理、对接费用说明，个人开发统一对接写法。
核心包含：

1. 钉钉考勤 API 双向同步开发规范；

2. 金蝶财务凭证推送、对账对接标准；

3. OSS 文件上传、图片画布存储约束；

4. 摊位地图 Fabric 前后端 JSON 序列化交互规则；

5. UI 主题前后端联动配置规范；

6. 第三方接口鉴权、失败重试、幂等防重复机制；

7. 各第三方平台收费额度说明。

## 8、统一安全开发规范

**文档描述**：前后端一体化安全约束，覆盖接口防护、数据脱敏、文件安全、账号权限、防注入 XSS、限流防重复，适配等保基础要求，个人开发避免安全漏洞。
核心包含：

1. 后端：SQL 注入拦截、接口越权校验、密码加密、限流、防重复提交；

2. 前端：XSS 过滤、敏感信息脱敏、token 安全管理；

3. 文件上传黑白名单、大小格式限制；

4. 手机号、身份证、商户隐私数据脱敏规则；

5. 高危操作（删除、批量修改、财务）安全校验规则；

6. 页面访问权限拦截标准。

## 9、业务设计 \+ 测试文档合集

**文档描述**：整合全业务模块需求设计 \+ 统一测试标准，一套文档包含所有业务流程、页面交互、验收要点，个人开发业务落地与自测统一依据，无需分开维护多份业务文档。
核心包含：

### 业务设计部分

1. 组织架构整体说明；

2. 租赁 / 水电 / 物资 / 巡检 / 营销 / 人事考勤 / 摊位地图 / OA / 财务各模块业务流程、页面功能、表关联关系；

### 测试规范部分

1. 功能自测通用标准；

2. 多租户隔离、权限越权专项测试要点；

3. 财务、地图、权限等高风险模块验收规则；

4. 接口异常、边界数据自测清单；

5. 上线前完整验收检查清单。
