# 统一优惠策略升级方案

> 创建时间：2026-09-05  
> 更新时间：2026-09-06  
> 升级目标：在现有租赁合同优惠基础上，扩展支持物业费、水电费等多业务类型的统一优惠管理

---

## 一、现有系统分析

### 1.1 现有优惠架构（已实现）

```
finance_discount_policy（优惠策略表）
  ├─ discount_type: 1免租期 2折扣率 3减免金额 4组合
  ├─ scope_type: 1按合同 2按铺位
  ├─ 集团模板 company_id=0 全子公司可见
  └─ 仅支持租赁合同优惠（source_type=contract）

finance_discount_apply（优惠申请表）
  ├─ source_type: contract（固定为合同来源）
  ├─ source_id: 合同ID
  ├─ policy_snapshot: 策略快照JSON
  ├─ need_audit: 超阈值自动审批
  └─ 审批通过 → 生成应收应付计划

合同优惠流程：
  合同保存 → 计算优惠 → 阈值判定 → 超阈值发起审批 → 审批通过 → 生成收款计划
```

### 1.2 现有账单表结构

```sql

-- 缺少：policy_id（关联优惠策略）、apply_id（关联优惠申请）

-- property_water_elec_bill（水电费账单表）关键字段

```

### 1.3 现有局限性

| 局限性 | 说明 |
|--------|------|
| **业务类型单一** | 仅支持租赁合同优惠（source_type=contract） |
| **优惠类型有限** | 仅支持免租期/折扣率/减免金额/组合，缺少定额优惠、阶梯优惠 |
| **适用范围固定** | 仅支持按合同/按铺位，缺少按租户/按市场/按分类 |
| **账单脱节** | finance_fee_pay_bill.discount_amount 未关联优惠策略，缺乏来源追溯 |
| **审批阈值固定** | 阈值通过配置表硬编码，不支持按业务类型配置 |

## 二、升级目标

### 2.1 核心目标

1. **统一策略管理**：一张策略表支持所有业务类型
2. **灵活适用范围**：支持按合同/铺位/租户/市场/分类配置
3. **扩展优惠类型**：新增定额优惠、阶梯优惠
4. **完整追溯链**：账单 ↔ 优惠申请 ↔ 优惠策略 可追溯
5. **审批阈值灵活**：支持按业务类型配置不同阈值

### 2.2 业务场景覆盖

| 业务类型 | 优惠场景 | 示例 |
|---------|---------|------|
| **租赁合同** | 免租期、折扣率、减免金额 | 开业免租3个月 |
| **物业费** | 定额减免、折扣率 | 每月减免200元物业费 |
| **水电费** | 定额减免、折扣率、阶梯优惠 | 消费满1000元打9折 |
| **幼儿园费** | 折扣率、减免金额 | 老学员9折优惠 |

## 四、优惠计算引擎设计

### 4.1 计算策略模式

```java
/**
 * 优惠计算策略接口
 */
public interface DiscountCalculator {
    /** 计算优惠金额 */
    BigDecimal calculate(BigDecimal originalAmount, BizDiscountApply apply);
    /** 判断是否支持该业务类型 */
    boolean support(String bizType);
}

/** 免租期计算 */
@Component
public class WaiveMonthsCalculator implements DiscountCalculator {
    public BigDecimal calculate(BigDecimal originalAmount, BizDiscountApply apply) {
        int totalMonths = apply.getTotalMonths();
        if (totalMonths <= 0) return BigDecimal.ZERO;
        return originalAmount.multiply(new BigDecimal(apply.getWaiveMonths()))
                .divide(new BigDecimal(totalMonths), 2, RoundingMode.HALF_UP);
    }
}

/** 折扣率计算 */
@Component
public class DiscountRateCalculator implements DiscountCalculator {
    public BigDecimal calculate(BigDecimal originalAmount, BizDiscountApply apply) {
        BigDecimal rate = apply.getDiscountRate().divide(new BigDecimal("100"), 4, RoundingMode.HALF_UP);
        return originalAmount.multiply(new BigDecimal("1").subtract(rate));
    }
}

/** 减免金额计算 */
@Component
public class DeductAmountCalculator implements DiscountCalculator {
    public BigDecimal calculate(BigDecimal originalAmount, BizDiscountApply apply) {
        return apply.getDeductAmount().min(originalAmount);
    }
}

/** 定额优惠计算 */
@Component
public class FixedAmountCalculator implements DiscountCalculator {
    public BigDecimal calculate(BigDecimal originalAmount, BizDiscountApply apply) {
        return apply.getFixedAmount().multiply(new BigDecimal(apply.getTotalMonths()));
    }
}

/** 阶梯优惠计算 */
@Component
public class TierCalculator implements DiscountCalculator {
    public BigDecimal calculate(BigDecimal originalAmount, BizDiscountApply apply) {
        List<TierConfig> tiers = parseTierConfig(apply.getTierConfig());
        for (TierConfig tier : tiers) {
            if (originalAmount.compareTo(tier.getMinAmount()) >= 0) {
                return originalAmount.multiply(new BigDecimal("1").subtract(tier.getDiscountRate().divide(new BigDecimal("100"), 4, RoundingMode.HALF_UP)));
            }
        }
        return BigDecimal.ZERO;
    }
}

/** 组合优惠计算 */
@Component
public class ComboCalculator implements DiscountCalculator {
    public BigDecimal calculate(BigDecimal originalAmount, BizDiscountApply apply) {
        BigDecimal total = BigDecimal.ZERO;
        if (apply.getWaiveMonths() > 0) {
            int totalMonths = apply.getTotalMonths();
            if (totalMonths > 0) {
                total = total.add(originalAmount.multiply(new BigDecimal(apply.getWaiveMonths()))
                        .divide(new BigDecimal(totalMonths), 2, RoundingMode.HALF_UP));
            }
        }
        if (apply.getDiscountRate().compareTo(new BigDecimal("100")) < 0) {
            BigDecimal rate = apply.getDiscountRate().divide(new BigDecimal("100"), 4, RoundingMode.HALF_UP);
            total = total.add(originalAmount.multiply(new BigDecimal("1").subtract(rate)));
        }
        if (apply.getDeductAmount().compareTo(BigDecimal.ZERO) > 0) {
            total = total.add(apply.getDeductAmount());
        }
        return total.min(originalAmount);
    }
}
```

### 4.2 计算器工厂

```java
@Component
public class DiscountCalculatorFactory {
    private final List<DiscountCalculator> calculators;
    
    public DiscountCalculator getCalculator(Integer discountType) {
        return switch (discountType) {
            case 1 -> calculators.stream().filter(c -> c instanceof WaiveMonthsCalculator).findFirst().orElseThrow();
            case 2 -> calculators.stream().filter(c -> c instanceof DiscountRateCalculator).findFirst().orElseThrow();
            case 3 -> calculators.stream().filter(c -> c instanceof DeductAmountCalculator).findFirst().orElseThrow();
            case 4 -> calculators.stream().filter(c -> c instanceof ComboCalculator).findFirst().orElseThrow();
            case 5 -> calculators.stream().filter(c -> c instanceof FixedAmountCalculator).findFirst().orElseThrow();
            case 6 -> calculators.stream().filter(c -> c instanceof TierCalculator).findFirst().orElseThrow();
            default -> throw new BizException("不支持的优惠类型: " + discountType);
        };
    }
}
```

### 5.3 账单生成时自动应用优惠

```java
/**
 * 账单生成时自动应用优惠
 */
@Service
public class DiscountBillApplyService {
    
    /**
     * 查询铺位某月份的有效优惠申请
     */
    public List<BizDiscountApply> listValidApplies(Long companyId, Long stallId, String billMonth, String bizType) {
        return applyMapper.selectList(new LambdaQueryWrapper<BizDiscountApply>()
                .eq(BizDiscountApply::getCompanyId, companyId)
                .eq(BizDiscountApply::getStallId, stallId)
                .eq(BizDiscountApply::getBizType, bizType)
                .eq(BizDiscountApply::getApplyStatus, CommonConst.APPLY_STATUS_PASS)
                .le(BizDiscountApply::getStartMonth, billMonth)
                .ge(BizDiscountApply::getEndMonth, billMonth)
                .orderByDesc(BizDiscountApply::getCreateTime));
    }
    
    /**
     * 应用优惠到统一账单
     */
    @Transactional(rollbackFor = Exception.class)
    public void applyToBill(Long billId, Long sourceBillId, Long stallId, String billMonth, String bizType, BigDecimal originalAmount) {
        List<BizDiscountApply> applies = listValidApplies(companyId, stallId, billMonth, bizType);
        
        BigDecimal totalDiscount = BigDecimal.ZERO;
        BizDiscountApply lastApply = null;
        
        for (BizDiscountApply apply : applies) {
            BigDecimal discount = calculatorFactory.calculateDiscount(originalAmount, apply);
            totalDiscount = totalDiscount.add(discount);
            lastApply = apply;
            
            // 记录执行日志
            saveDiscountLog(apply, billId, sourceBillId, discount, originalAmount);
        }
        
        // 更新统一账单优惠金额
        feeBillMapper.update(null, new LambdaUpdateWrapper<FinanceFeePayBill>()
                .eq(FinanceFeePayBill::getId, billId)
                .set(FinanceFeePayBill::getDiscountAmount, totalDiscount)
                .set(FinanceFeePayBill::getRealAmount, originalAmount.subtract(totalDiscount))
                .set(lastApply != null, FinanceFeePayBill::getPolicyId, lastApply.getPolicyId())
                .set(lastApply != null, FinanceFeePayBill::getApplyId, lastApply.getId())
                .set(lastApply != null, FinanceFeePayBill::getDiscountType, lastApply.getDiscountType()));
    }
}
```

### 6.2 阈值判断逻辑

```java
/**
 * 判断是否需要审批
 */
public int checkNeedAudit(BizDiscountApply apply, BigDecimal originalAmount) {
    Long companyId = apply.getCompanyId();
    String bizType = apply.getBizType();
    
    // 1. 免租期阈值
    if (apply.getWaiveMonths() > 0) {
        BizDiscountThreshold t = thresholdMapper.selectOne(...);
        if (t != null && apply.getWaiveMonths() > t.getThresholdValue().intValue()) {
            return CommonConst.APPLY_NEED_AUDIT_YES;
        }
    }
    
    // 2. 折扣率阈值
    if (apply.getDiscountRate().compareTo(new BigDecimal("100")) < 0) {
        BizDiscountThreshold t = thresholdMapper.selectOne(...);
        if (t != null && apply.getDiscountRate().compareTo(t.getThresholdValue()) < 0) {
            return CommonConst.APPLY_NEED_AUDIT_YES;
        }
    }
    
    // 3. 减免金额阈值
    if (apply.getDeductAmount().compareTo(BigDecimal.ZERO) > 0) {
        BizDiscountThreshold t = thresholdMapper.selectOne(...);
        if (t != null && apply.getDeductAmount().compareTo(t.getThresholdValue()) > 0) {
            return CommonConst.APPLY_NEED_AUDIT_YES;
        }
    }
    
    // 4. 定额优惠阈值
    if (apply.getFixedAmount().compareTo(BigDecimal.ZERO) > 0) {
        BizDiscountThreshold t = thresholdMapper.selectOne(...);
        if (t != null && apply.getFixedAmount().compareTo(t.getThresholdValue()) > 0) {
            return CommonConst.APPLY_NEED_AUDIT_YES;
        }
    }
    
    // 5. 占比阈值
    if (originalAmount.compareTo(BigDecimal.ZERO) > 0) {
        BizDiscountThreshold t = thresholdMapper.selectOne(...);
        if (t != null) {
            BigDecimal ratio = apply.getDiscountAmount().divide(originalAmount, 4, RoundingMode.HALF_UP)
                .multiply(new BigDecimal("100"));
            if (ratio.compareTo(t.getThresholdValue()) > 0) {
                return CommonConst.APPLY_NEED_AUDIT_YES;
            }
        }
    }
    
    return CommonConst.APPLY_NEED_AUDIT_NO;
}
```

## 十一、实用场景设计

### 11.1 场景一：物业费定额减免

**业务需求**：某市场所有租户，每月减免200元物业费，连续减免6个月。

**配置方式**：
```
策略名称: 市场A物业费减免
业务类型: property_fee
优惠类型: 5定额优惠
定额金额: 200.00 元/月
适用范围: 按市场
范围ID: [市场A的ID]
生效时间: 2024-06-01 至 2024-11-30
最多申请月数: 6
自动审批: 是
```

**执行效果**：
- 生成2024-06至2024-11的物业费账单时，自动应用优惠
- 每月账单优惠金额 = 200元
- 实收金额 = 原价 - 200元

### 11.2 场景二：水电费阶梯优惠

**业务需求**：某租户每月水电费消费满1000元打9折，满2000元打8折。

**配置方式**：
```
策略名称: 大客户阶梯优惠
业务类型: water_elec
优惠类型: 6阶梯优惠
阶梯配置: [{"min_amount":1000,"discount_rate":90},{"min_amount":2000,"discount_rate":80}]
适用范围: 按租户
范围ID: [租户ID]
生效时间: 永久
自动审批: 否
```

**执行效果**：
- 水电费账单生成时，根据消费金额匹配阶梯
- 1000元 ≤ 消费 < 2000元：打9折
- 消费 ≥ 2000元：打8折

### 11.3 场景三：临时活动优惠

**业务需求**：某市场举办活动，活动期间所有租户物业费减免30%。

```
策略名称: 周年庆活动优惠

适用范围: 按市场
```

- 2024年10月的物业费账单自动应用7折优惠
- 11月起恢复原价

## 十二、关键设计原则

| 原则 | 说明 |
|-----|------|
| **统一抽象** | 一张策略表支持所有业务类型，通过 biz_type 区分 |
| **快照固化** | 申请时快照策略参数，审批通过后不回溯 |
| **策略模式** | 优惠计算使用策略模式，易于扩展新类型 |
| **阈值灵活** | 支持按业务类型配置不同审批阈值 |
| **完整追溯** | 账单 ↔ 优惠申请 ↔ 优惠策略 可追溯 |
| **多租户隔离** | 所有查询自动附加 company_id 条件 |
| **向后兼容** | 现有租赁合同优惠不受影响 |

---

## 十三、注意事项

1. **性能考虑**
   - 优惠计算应在账单生成时异步执行，避免阻塞
   - 大量账单生成时考虑分批处理

2. **并发控制**
   - 同一铺位同月份只能生成一次账单
   - 优惠申请审批流程需考虑并发场景

3. **数据一致性**
   - 优惠金额计算需与账单金额保持精确一致
   - 审批通过后需保证优惠金额不被修改

4. **审计追溯**
   - 所有优惠申请需记录操作日志
   - 审批流程需记录审批意见
