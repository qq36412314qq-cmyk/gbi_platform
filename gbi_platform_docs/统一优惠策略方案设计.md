# 统一优惠策略方案设计

> 创建时间：2026-09-05  
> 设计目标：支持租赁费、物业费、水电费、幼儿园费等多种收费类型的统一优惠管理

---

## 一、现有系统分析

### 1.1 现有优惠架构（局限性）

```
biz_discount_policy（优惠策略表）
  ├─ discount_type: 1免租期 2折扣率 3减免金额 4组合
  ├─ scope_type: 1按合同 2按铺位
  └─ 仅支持租赁合同优惠（source_type=contract）

biz_discount_apply（优惠申请单）
  ├─ source_type: contract（固定）
  ├─ source_id: 合同ID
  └─ 无法适配其他业务类型
```

### 1.2 现有账单表

```
biz_fee_bill（统一账单表）
  ├─ biz_type: property_fee/water_elec/rent/kindergarten
  ├─ discount_amount: 优惠减免金额（未关联策略）
  └─ 缺乏优惠来源追溯
```

## 四、优惠计算引擎设计

### 4.1 计算策略模式

```java
/**
 * 优惠计算策略接口
 */
public interface DiscountCalculator {
    
    /**
     * 计算优惠金额
     * @param originalAmount 原价金额
     * @param apply 优惠申请
     * @return 优惠金额
     */
    BigDecimal calculate(BigDecimal originalAmount, BizDiscountApply apply);
    
    /**
     * 判断是否支持该业务类型
     */
    boolean support(String bizType);
}

/**
 * 免租期优惠计算
 */
@Component
public class WaiveMonthsCalculator implements DiscountCalculator {
    @Override
    public BigDecimal calculate(BigDecimal originalAmount, BizDiscountApply apply) {
        // 免租期 = 原价 × (免租月数 / 总月数)
        int totalMonths = apply.getTotalMonths();
        if (totalMonths <= 0) return BigDecimal.ZERO;
        return originalAmount.multiply(new BigDecimal(apply.getWaiveMonths()))
                .divide(new BigDecimal(totalMonths), 2, RoundingMode.HALF_UP);
    }
    
    @Override
    public boolean support(String bizType) {
        return true; // 所有业务类型支持
    }
}

/**
 * 折扣率优惠计算
 */
@Component
public class DiscountRateCalculator implements DiscountCalculator {
    @Override
    public BigDecimal calculate(BigDecimal originalAmount, BizDiscountApply apply) {
        // 折扣优惠 = 原价 × (1 - 折扣率/100)
        BigDecimal rate = apply.getDiscountRate().divide(new BigDecimal("100"), 4, RoundingMode.HALF_UP);
        return originalAmount.multiply(new BigDecimal("1").subtract(rate));
    }
    
    @Override
    public boolean support(String bizType) {
        return true;
    }
}

/**
 * 减免金额优惠计算
 */
@Component
public class DeductAmountCalculator implements DiscountCalculator {
    @Override
    public BigDecimal calculate(BigDecimal originalAmount, BizDiscountApply apply) {
        // 直接返回减免金额，不超过原价
        return apply.getDeductAmount().min(originalAmount);
    }
    
    @Override
    public boolean support(String bizType) {
        return true;
    }
}

/**
 * 定额优惠计算
 */
@Component
public class FixedAmountCalculator implements DiscountCalculator {
    @Override
    public BigDecimal calculate(BigDecimal originalAmount, BizDiscountApply apply) {
        // 定额优惠 = 固定金额 × 月数
        return apply.getFixedAmount().multiply(new BigDecimal(apply.getTotalMonths()));
    }
    
    @Override
    public boolean support(String bizType) {
        return true;
    }
}

/**
 * 阶梯优惠计算
 */
@Component
public class TierCalculator implements DiscountCalculator {
    @Override
    public BigDecimal calculate(BigDecimal originalAmount, BizDiscountApply apply) {
        // 根据阶梯配置计算
        List<TierConfig> tiers = parseTierConfig(apply.getTierConfig());
        for (TierConfig tier : tiers) {
            if (originalAmount.compareTo(tier.getMinAmount()) >= 0) {
                return originalAmount.multiply(new BigDecimal("1").subtract(tier.getDiscountRate().divide(new BigDecimal("100"), 4, RoundingMode.HALF_UP)));
            }
        }
        return BigDecimal.ZERO;
    }
    
    @Override
    public boolean support(String bizType) {
        return true;
    }
}

/**
 * 组合优惠计算
 */
@Component
public class ComboCalculator implements DiscountCalculator {
    @Override
    public BigDecimal calculate(BigDecimal originalAmount, BizDiscountApply apply) {
        BigDecimal total = BigDecimal.ZERO;
        // 免租期部分
        if (apply.getWaiveMonths() > 0) {
            int totalMonths = apply.getTotalMonths();
            if (totalMonths > 0) {
                total = total.add(originalAmount.multiply(new BigDecimal(apply.getWaiveMonths()))
                        .divide(new BigDecimal(totalMonths), 2, RoundingMode.HALF_UP));
            }
        }
        // 折扣率部分
        if (apply.getDiscountRate().compareTo(new BigDecimal("100")) < 0) {
            BigDecimal rate = apply.getDiscountRate().divide(new BigDecimal("100"), 4, RoundingMode.HALF_UP);
            total = total.add(originalAmount.multiply(new BigDecimal("1").subtract(rate)));
        }
        // 减免金额部分
        if (apply.getDeductAmount().compareTo(BigDecimal.ZERO) > 0) {
            total = total.add(apply.getDeductAmount());
        }
        return total.min(originalAmount);
    }
    
    @Override
    public boolean support(String bizType) {
        return true;
    }
}
```

### 4.2 优惠计算器工厂

```java
@Component
public class DiscountCalculatorFactory {
    
    private final List<DiscountCalculator> calculators;
    
    public DiscountCalculatorFactory(List<DiscountCalculator> calculators) {
        this.calculators = calculators;
    }
    
    public DiscountCalculator getCalculator(Integer discountType) {
        return switch (discountType) {
            case 1 -> calculators.stream()
                    .filter(c -> c instanceof WaiveMonthsCalculator)
                    .findFirst().orElseThrow();
            case 2 -> calculators.stream()
                    .filter(c -> c instanceof DiscountRateCalculator)
                    .findFirst().orElseThrow();
            case 3 -> calculators.stream()
                    .filter(c -> c instanceof DeductAmountCalculator)
                    .findFirst().orElseThrow();
            case 4 -> calculators.stream()
                    .filter(c -> c instanceof ComboCalculator)
                    .findFirst().orElseThrow();
            case 5 -> calculators.stream()
                    .filter(c -> c instanceof FixedAmountCalculator)
                    .findFirst().orElseThrow();
            case 6 -> calculators.stream()
                    .filter(c -> c instanceof TierCalculator)
                    .findFirst().orElseThrow();
            default -> throw new BizException("不支持的优惠类型: " + discountType);
        };
    }
    
    public BigDecimal calculateDiscount(BigDecimal originalAmount, BizDiscountApply apply) {
        DiscountCalculator calculator = getCalculator(apply.getDiscountType());
        return calculator.calculate(originalAmount, apply);
    }
}
```

## 五、优惠应用流程设计

### 5.1 账单生成时自动应用优惠

```
账单生成流程
    ↓
查询该铺位该月份的有效优惠申请
    ↓
有优惠申请 → 计算优惠金额 → 写入 biz_fee_bill.discount_amount
无优惠申请 → discount_amount = 0
```

### 5.2 优惠应用服务

```java
@Service
@RequiredArgsConstructor
public class DiscountApplyService {
    
    private final BizDiscountApplyMapper applyMapper;
    private final BizDiscountPolicyMapper policyMapper;
    private final BizFeeBillMapper feeBillMapper;
    private final DiscountCalculatorFactory calculatorFactory;
    
    /**
     * 查询铺位某月份的有效优惠申请
     */
    public List<BizDiscountApply> listValidApplies(Long companyId, Long stallId, String billMonth) {
        return applyMapper.selectList(new LambdaQueryWrapper<BizDiscountApply>()
                .eq(BizDiscountApply::getCompanyId, companyId)
                .eq(BizDiscountApply::getStallId, stallId)
                .eq(BizDiscountApply::getBizType, resolveBizType(billMonth)) // 根据账单类型确定
                .eq(BizDiscountApply::getApplyStatus, CommonConst.APPLY_STATUS_PASS)
                .le(BizDiscountApply::getStartMonth, billMonth)
                .ge(BizDiscountApply::getEndMonth, billMonth)
                .orderByDesc(BizDiscountApply::getCreateTime));
    }
    
    /**
     * 应用优惠到账单
     */
    @Transactional(rollbackFor = Exception.class)
    public void applyToBill(Long billId, Long stallId, String billMonth, BigDecimal originalAmount) {
        List<BizDiscountApply> applies = listValidApplies(UserContext.getLoginUser().getCompanyId(), stallId, billMonth);
        
        BigDecimal totalDiscount = BigDecimal.ZERO;
        for (BizDiscountApply apply : applies) {
            BigDecimal discount = calculatorFactory.calculateDiscount(originalAmount, apply);
            totalDiscount = totalDiscount.add(discount);
            
            // 记录优惠执行明细
            saveDiscountLog(apply, billId, discount);
        }
        
        // 更新账单优惠金额
        feeBillMapper.update(null, new LambdaUpdateWrapper<BizFeeBill>()
                .eq(BizFeeBill::getId, billId)
                .set(BizFeeBill::getDiscountAmount, totalDiscount)
                .set(BizFeeBill::getRealAmount, originalAmount.subtract(totalDiscount)));
    }
    
    /**
     * 保存优惠执行日志
     */
    private void saveDiscountLog(BizDiscountApply apply, Long billId, BigDecimal discount) {
        BizDiscountLog log = new BizDiscountLog();
        log.setCompanyId(apply.getCompanyId());
        log.setApplyId(apply.getId());
        log.setBillId(billId);
        log.setStallId(apply.getStallId());
        log.setDiscountType(apply.getDiscountType());
        log.setOriginalAmount(apply.getOriginalAmount());
        log.setDiscountAmount(discount);
        log.setRealAmount(apply.getOriginalAmount().subtract(discount));
        log.setCreateBy(UserContext.getUserIdOrZero());
        discountLogMapper.insert(log);
    }
}
```

### 6.2 阈值判断逻辑

```java
/**
 * 判断是否需要审批
 */
public int checkNeedAudit(BizDiscountApply apply, BigDecimal originalAmount) {
    Long companyId = apply.getCompanyId();
    String bizType = apply.getBizType();
    
    // 1. 免租期阈值
    List<BizDiscountThreshold> waiveThresholds = thresholdMapper.selectList(
        new LambdaQueryWrapper<BizDiscountThreshold>()
            .eq(BizDiscountThreshold::getCompanyId, companyId)
            .eq(BizDiscountThreshold::getBizType, bizType)
            .eq(BizDiscountThreshold::getThresholdType, 1)
            .eq(BizDiscountThreshold::getStatus, 1));
    for (BizDiscountThreshold t : waiveThresholds) {
        if (apply.getWaiveMonths() > t.getThresholdValue().intValue()) {
            return CommonConst.APPLY_NEED_AUDIT_YES;
        }
    }
    
    // 2. 折扣率阈值
    List<BizDiscountThreshold> rateThresholds = thresholdMapper.selectList(
        new LambdaQueryWrapper<BizDiscountThreshold>()
            .eq(BizDiscountThreshold::getCompanyId, companyId)
            .eq(BizDiscountThreshold::getBizType, bizType)
            .eq(BizDiscountThreshold::getThresholdType, 2)
            .eq(BizDiscountThreshold::getStatus, 1));
    for (BizDiscountThreshold t : rateThresholds) {
        if (apply.getDiscountRate().compareTo(t.getThresholdValue()) < 0) {
            return CommonConst.APPLY_NEED_AUDIT_YES;
        }
    }
    
    // 3. 减免金额阈值
    List<BizDiscountThreshold> deductThresholds = thresholdMapper.selectList(
        new LambdaQueryWrapper<BizDiscountThreshold>()
            .eq(BizDiscountThreshold::getCompanyId, companyId)
            .eq(BizDiscountThreshold::getBizType, bizType)
            .eq(BizDiscountThreshold::getThresholdType, 3)
            .eq(BizDiscountThreshold::getStatus, 1));
    for (BizDiscountThreshold t : deductThresholds) {
        if (apply.getDeductAmount().compareTo(t.getThresholdValue()) > 0) {
            return CommonConst.APPLY_NEED_AUDIT_YES;
        }
    }
    
    // 4. 定额优惠阈值
    List<BizDiscountThreshold> fixedThresholds = thresholdMapper.selectList(
        new LambdaQueryWrapper<BizDiscountThreshold>()
            .eq(BizDiscountThreshold::getCompanyId, companyId)
            .eq(BizDiscountThreshold::getBizType, bizType)
            .eq(BizDiscountThreshold::getThresholdType, 4)
            .eq(BizDiscountThreshold::getStatus, 1));
    for (BizDiscountThreshold t : fixedThresholds) {
        if (apply.getFixedAmount().compareTo(t.getThresholdValue()) > 0) {
            return CommonConst.APPLY_NEED_AUDIT_YES;
        }
    }
    
    // 5. 占比阈值
    List<BizDiscountThreshold> ratioThresholds = thresholdMapper.selectList(
        new LambdaQueryWrapper<BizDiscountThreshold>()
            .eq(BizDiscountThreshold::getCompanyId, companyId)
            .eq(BizDiscountThreshold::getBizType, bizType)
            .eq(BizDiscountThreshold::getThresholdType, 5)
            .eq(BizDiscountThreshold::getStatus, 1));
    if (originalAmount.compareTo(BigDecimal.ZERO) > 0) {
        for (BizDiscountThreshold t : ratioThresholds) {
            BigDecimal ratio = apply.getDiscountAmount().divide(originalAmount, 4, RoundingMode.HALF_UP)
                .multiply(new BigDecimal("100"));
            if (ratio.compareTo(t.getThresholdValue()) > 0) {
                return CommonConst.APPLY_NEED_AUDIT_YES;
            }
        }
    }
    
    return CommonConst.APPLY_NEED_AUDIT_NO;
}
```

## 十一、关键设计原则

| 原则 | 说明 |
|-----|------|
| **统一抽象** | 一张策略表支持所有业务类型，通过 biz_type 区分 |
| **快照固化** | 申请时快照策略参数，审批通过后不回溯 |
| **策略模式** | 优惠计算使用策略模式，易于扩展新类型 |
| **阈值灵活** | 支持按业务类型配置不同审批阈值 |
| **可追溯** | 执行日志完整记录每笔优惠计算过程 |
| **多租户隔离** | 所有查询自动附加 company_id 条件 |
