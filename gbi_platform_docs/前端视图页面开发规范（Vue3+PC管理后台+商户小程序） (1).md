# 前端视图页面开发规范（Vue3\+PC管理后台\+商户小程序）

## 文档描述

本规范统一 PC 管理后台（Vue3\+Vite\+TS）、商户微信小程序全套前端开发标准，覆盖项目目录、命名、路由菜单、组件、表单表格、接口请求、权限、UI 视觉、主题配置、摊位可视化 Fabric 画布、打印导出、性能、安全、交互、小程序适配全维度约束；完全对齐《集团多业态一体化管控系统》整体业务、后端 API、权限清单、API \& 日志规范，单人独立开发统一编码风格，保证前后端字段对齐、页面复用高、权限管控统一、视觉风格标准化，降低联调、迭代、维护成本。

## 一、整体技术栈标准

### 1\.1 PC 管理后台

- 基础框架：Vue3 \+ Vite \+ TypeScript

- UI 组件库：Element Plus

- 状态管理：Pinia

- 请求工具：Axios

- 可视化图表：ECharts（集团数据大屏专用）

- 工具依赖：dayjs \(日期\)、lodash \(通用方法\)、xlsx \(Excel 导出\)、print\-js \(打印\)

- 画布专属：Fabric\.js ^5\.3\.0（摊位平面图模块）

### 1\.2 商户微信小程序

- 技术方案：原生微信小程序 \+ Vant Weapp

- 配套工具：dayjs、微信支付原生 API

## 三、全局命名强制规范

### 3\.1 目录与文件命名

1. 文件夹：全小写，横线分隔 `stall-map`

2. Vue 页面：小驼峰 `stallList.vue`

3. TS 接口文件：小驼峰 `marketMap.ts`

4. 通用 / 业务组件：大驼峰 `MarketCanvas.vue`

5. 路由 name：页面对应大驼峰 `StallMap`

### 3\.2 变量、常量、TS 类型

1. 普通变量：小驼峰 `stallStatusList`

2. 常量：全大写下划线 `STATUS_EMPTY`

3. 请求函数：动词 \+ 名词 `getMarketList`

4. TS 接口 / DTO/VO：大驼峰，与后端字段完全对齐

### 3\. CSS 类名规范

1. 页面根类：页面目录前缀 `stall-map-wrap`

2. 通用样式前缀`g-`，业务样式前缀`b-`

3. 禁止纯数字、无意义短类名

## 四、路由与菜单统一规范

1. `router/index.ts` 路由与后台菜单、权限一一对应；

2. 路由 meta 固定三元组配置：

```ts
meta: {
  title: '摊位可视化地图',
  icon: 'map',
  permission: 'stall:map:list',
  isCache: true
}
```

3. 全局前置路由拦截：无 token / 无权限自动跳转 403 登录页；

4. 分公司账号自动过滤无权限路由，集团展示全部菜单。

## 五、页面标准布局模板（全页面强制统一）

### 5\.1 列表四区块模板（所有台账页面）

1. 顶部操作区：页面标题 \+ 新增 / 导出 / 打印等`AuthBtn`权限按钮；

2. 搜索筛选区：统一封装 SearchBar 组件；

3. 表格展示区：TablePage 通用表格 \+ 分页；

4. 弹窗区域：新增 / 编辑 / 详情独立弹窗组件。

### 5\.2 表单页面规范

统一 el\-form 卡片包裹，分基础信息、附属信息、附件三块；底部统一提交 / 重置 / 取消按钮。

### 5\.3 详情页面规范

卡片分组展示信息，关联单据用折叠面板 / 子表格，底部放置打印、导出、返回按钮。

## 六、组件开发规范

### 6\.1 通用公共组件 components/common

SearchBar、TablePage、AuthBtn、UploadFile、ExportBtn、PrintBtn、CommonDialog，全项目统一复用，禁止重复开发。

### 6\.2 业务通用组件 components/business

摊位选择器、商户选择器、流程卡片、**MarketCanvas 画布组件**（编辑 / 只读双模式）。

### 6\.3 组件强制约束

1. Props 使用 TS 严格类型校验，必填项标记；

2. 数据通过 emit 事件向上传递，禁止子组件直接修改父数据；

3. 复杂弹窗、独立页面拆分为单独组件，控制页面代码行数；

4. main\.ts 统一全局注册通用组件，页面无需重复引入。

## 七、表单开发统一规则

1. 统一 el\-form，绑定全局查询 / 提交对象；

2. 全部输入框配置校验规则（非空、手机号、金额、数字长度）；

3. 金额输入限制两位小数，日期统一 dayjs 格式化；

4. 下拉选项从 Pinia 全局字典读取，禁止硬编码；

5. 区分新增 / 编辑状态，ID 字段只读；

6. 弹窗关闭自动清空表单与校验提示。

## 八、表格开发统一规则

1. 全部使用封装 TablePage，自带分页；

2. 超长文本省略 \+ tooltip 悬浮查看；

3. 状态自动调用 dict 转换文字；

4. 操作列统一放置查看 / 编辑 / 缴费按钮，通过 AuthBtn 鉴权；

5. 支持批量多选、批量导出、批量作废；

6. 大数据列表添加防抖查询，减少请求频率。

## 九、API 请求统一规范

### 9\.1 request\.ts 全局封装

1. 请求头自动携带 token；

2. 统一返回 JSON 结构：

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {}
}
```

3. 全局错误拦截：401 自动登出、403 无权限弹窗、500 统一提示；

4. 所有接口自动开启 loading，请求结束关闭；

5. 区分开发 / 生产环境 baseURL，生产强制 HTTPS。

### 9\.2 api 业务文件规范

1. 一个业务模块对应一个 ts 文件（marketMap\.ts 专属画布接口）；

2. 请求统一 async/await，不使用\.then 链式；

3. 请求参数 TS DTO 与后端 DTO 字段完全对齐；

4. 文件上传、导出接口单独处理二进制流。

### 9\.3 摊位画布专属 7 个接口清单

1. getMarketList：分页查询当前公司地图，自动过滤 company\_id

2. addMarket：上传底图新增地图

3. updateMarket：修改地图、替换底图

4. deleteMarket：删除地图（高危鉴权 stall:map:edit）

5. saveMapPoints：提交画布序列化 JSON，前端过滤脚本字符

6. getMarketDetail：获取底图 \+ 点位 JSON 用于画布还原

7. getStallStatusByMarket：获取摊位状态，自动上色

## 十、前端 RB 权限控制规范（与后端完全对齐）

1. **页面权限**：路由 meta\.permission 拦截，无权限 403；

2. **按钮权限**统一`<AuthBtn permission="stall:map:edit">`，无权限自动隐藏；

    - stall:list 摊位基础查看

    - stall:map:list 地图页面查看

    - stall:map:edit 画布编辑、上传底图、批量点位修改、删除地图（敏感二级复核权限）

    - stall:map:export 地图导出打印

3. **数据权限**：前端仅做页面隐藏，company\_id 数据过滤全部由后端 MyBatis-Plus 拦截器实现，前端不处理数据过滤逻辑。

## 十一、全局现代极简扁平化 UI 视觉规范

### 11\.1 核心设计原则

去噪极简、层级优先、全局统一、功能至上、轻分层质感（弱阴影区分层级，无厚重立体）。

### 11\.2 全局色彩体系（全部使用 CSS 变量，禁止硬编码）

- \-\-color\-primary 集团主蓝（按钮 / 选中高亮）

- \-\-color\-success\-light 空置摊位底色

- \-\-color\-warning 即将到期摊位

- \-\-color\-danger 欠费摊位

- 多级中性灰度区分背景、边框、文字

> 成功 / 警告 / 危险状态色不可自定义修改，仅主色支持后台 UI 配置自定义。
> 
> 

### 11\.3 字体、排版统一

固定字号层级：18 大标题 /16 模块标题 /14 正文 /13 备注 /12 小字；行高统一 1\.5 倍；文本左对齐，数字金额右对齐。

### 11\.4 卡片、按钮、表格规范

统一中等柔和圆角、细浅分割线、微弱悬浮阴影；按钮扁平化无渐变；表格支持无边框 / 斑马纹两种预设。

### 11\.5 深浅主题适配

浅色默认办公模式、深色护眼模式，切换自动更新画布、表格、组件颜色，无样式错乱。

## 十二、UI 主题自定义配置配套规范

### 12\.1 架构规则

全部样式基于`:root`全局 CSS 变量，无固定色值、圆角；配置从后端`sys_ui_theme`表读取，company\_id 隔离集团 / 子公司配置。

### 12\.2 可配置项

1. 系统主色（仅低饱和商务色）；

2. 导航布局（侧边 / 顶部）；

3. 卡片圆角、表格样式；

4. 浅色 / 深色 / 跟随系统模式。

### 12\.3 前端实现约束

1. 登录自动拉取本公司主题存入 Pinia；

2. 保存配置实时全局生效，无需刷新页面；

3. 画布 MarketCanvas 自动读取主题变量更新摊位填充色；

4. 商户小程序同步对应子公司主色调。

## 十三、摊位可视化 Fabric 画布模块专项规范（第十九章完整规范）

### 13\.1 技术约束

固定依赖 fabric:^5\.3\.0，**禁止接入高德 / 百度 GIS 地图**，仅静态图片画布方案。
适用场景：园区手绘平面图、室内摊位不规则布局。

### 13\.2 目录分层

src/api/marketMap\.ts、src/utils/fabricUtil\.ts、components/business/MarketCanvas\.vue、views/business/stall\-map/stallMap\.vue

### 13\.3 MarketCanvas 组件双模式

1. read 只读：仅缩放平移、点击查看，隐藏绘制 / 删除 / 拖拽；集团账号默认只读；

2. edit 编辑：矩形 / 多边形绘制、拖拽调整、绑定 stallId、批量刷新状态；子公司运营账号默认编辑。

### 13\.4 fabricUtil 工具统一封装能力

1. 画布初始化、锁定底图不可拖动；

2. 图形创建，每个图形挂载 stallId 自定义属性；

3. 根据摊位 status 自动匹配主题变量上色；

4. 序列化 JSON 导出 / 反序列化还原画布；

5. 撤销 / 重做栈；

6. 画布导出 PNG；

7. 页面销毁销毁 canvas 实例，释放内存。

### 13\.5 stallMap 页面四区块布局

顶部操作按钮（新增 / 保存 / 导出 AuthBtn 鉴权）、画布工具栏、中央画布、右侧摊位属性面板；点击摊位复用摊位详情弹窗，与摊位管理页面功能同源。

### 13\.6 交互、安全、性能规则

1. 空白画布点击无响应，仅摊位图形触发弹窗；

2. 删除地图 / 批量点位修改弹出二次确认；

3. 页面存在未保存变更，关闭弹窗提示；

4. JSON 提交前端过滤\<、onload 等恶意脚本，防注入；

5. 单市场摊位超 300 启用分层渲染；

6. 画布状态列表 5 分钟前端缓存，减少请求；

7. 路由懒加载，减少首包体积。

### 13\.7 商户小程序画布约束

小程序不引入 Fabric，仅展示静态底图图片，仅高亮商户自身摊位，无编辑导出功能。

### 13\.8 画布开发红线

1. 禁止硬编码色值、圆角；

2. 禁止重复编写 Fabric 底层逻辑，统一复用 fabricUtil；

3. 禁止绕过 AuthBtn 展示编辑高危按钮；

4. 禁止前端本地持久化点位 JSON，全部后端存储；

5. 禁止接入第三方在线地图 API。

## 十四、打印 \& 导出统一规范

1. Excel 导出统一 ExportBtn，支持当前页 / 全部数据筛选导出；

2. 打印使用 PrintBtn，单独打印模板，隐藏搜索栏分页控件；

3. 导出文件名统一 `模块名称_年月日.xlsx`；

4. 合同、摊位平面图、账单统一 A4 适配打印布局。

## 十五、数据格式化工具 utils/format\.ts

全局统一调用，禁止页面各自写转换逻辑：

- formatMoney：金额保留两位小数

- formatDate /formatDateTime：标准日期

- formatPhone：手机号脱敏 138\\*\\*\*\*1234

- getDictLabel：字典值转文字

## 十六、前端安全开发规范

1. 存储安全：token 仅 Pinia\+localStorage，退出清空，不持久化身份证 / 手机号；

2. 传输安全：全 HTTPS，提交前过滤 XSS 脚本字符；

3. 防重复提交：缴费、点位保存、调拨按钮提交后禁用；

4. 文件安全：上传拦截 exe/html/js，限制图片尺寸大小；

5. 信息脱敏：普通用户不展示完整手机号、证件号；

6. 异常屏蔽：前端不展示后端堆栈报错，统一友好提示。

## 十七、页面性能规范

1. 长列表开启虚拟滚动，减少 DOM 节点；

2. 页面销毁清除定时器、ECharts、Fabric 画布实例；

3. 字典、摊位状态列表添加前端缓存；

4. 图片统一压缩懒加载；

5. 路由懒加载拆分页面代码。

## 十八、通用交互统一规范

1. 新增 / 编辑提交成功自动关闭弹窗并刷新表格；

2. 删除、作废操作强制二次确认弹窗；

3. 欠费、库存、到期数据红色警告提示；

4. 批量操作完成弹出统计 Toast；

5. 网络 / 接口异常统一轻提示，不阻塞操作。

## 十九、商户微信小程序补充规范

1. 仅保留账单查询、缴费、活动查看、个人摊位静态图，无后台管理功能；

2. 无画布编辑逻辑，仅静态展示市场平面图；

3. 支付流程单独封装，支付成功自动刷新账单；

4. 轻量化页面，大列表改用列表替代复杂表格；

5. 同步所属公司 UI 主色调，保持品牌视觉统一。

## 二十、开发强制红线（禁止行为）

1. 禁止硬编码色、圆角、间距，必须使用全局 CSS 变量适配主题；

2. 禁止页面直接操作 company\_id，数据过滤由后端处理；

3. 禁止绕过 AuthBtn 渲染新增 / 删除 / 导出高危按钮；

4. 禁止重复封装接口、画布、表格逻辑，统一复用全局工具组件；

5. 禁止本地存储业务敏感数据、画布完整点位 JSON；

6. 禁止开发环境、生产环境混用接口域名；

7. 画布模块禁止接入第三方 GIS 地图，强制 Fabric 静态画布方案。
