# 代码注释规范

> 目的：统一前后端代码注释风格，提升代码可读性和维护效率。
> 适用范围：`gbi_platform_server`（Java后端）+ `gbi_platform_admin`（Vue前端）

---

## 一、通用原则

1. **所有注释使用简体中文**，禁止英文注释
2. **注释与代码分离**：不解释代码在做什么（代码已表达），解释为什么这么做
3. **关键位置必须注释**：复杂逻辑、业务规则、特殊处理
4. **及时更新注释**：代码变更时同步更新注释
5. **禁止无意义注释**：如 `// 结束大括号` 等冗余注释

---

## 二、Java 后端注释规范

### 2.1 类注释

**所有 public 类必须添加类注释**：

```java
/**
 * 物业费月度账单服务实现
 * 
 * 支持按月批量生成、单条生成、预览、同步到统一账单表等功能。
 * 数据表：property_bill、biz_fee_bill
 * 
 * @author gbi
 * @since 2026-08-28
 */
@Slf4j
@Service
@RequiredArgsConstructor
public class PropertyFeeBillServiceImpl implements PropertyFeeBillService {
```

**注释内容包含**：
- 功能简述
- 涉及的数据表（如有）
- @author 和 @since 版本信息

### 2.2 方法注释

**所有 public 方法必须添加方法注释**：

```java
/**
 * 同步已有账单记录到未支付订单（biz_fee_bill）

 *
 * @param id 账单记录ID
 * @return 操作结果提示信息
 */
@Override
public String syncToUnpaidBill(Long id) {
```

**注释内容包含**：
- 功能说明
- 特殊处理说明（幂等、异常处理等）
- @param 参数说明
- @return 返回值说明

### 2.3 行内注释

**复杂逻辑、业务规则处添加行内注释**：

```java
// 计算账单金额：使用期数因子调整月度费用
BigDecimal periodFactor = bill.getPeriodFactor() != null ? bill.getPeriodFactor() : BigDecimal.ONE;
BigDecimal amount = bill.getAmount().multiply(periodFactor).setScale(2, RoundingMode.HALF_UP);

// 账单已存在则跳过，避免重复生成（唯一键：company_id + stall_id + rule_id + bill_month）
Long exists = bizFeeBillMapper.selectCount(new LambdaQueryWrapper<BizFeeBill>()
        .eq(BizFeeBill::getSourceBillId, bill.getId()));
if (exists != null && exists > 0) {
    log.info("账单已存在，跳过同步：propertyBillId={}", id);
    return "订单已存在，无需重复生成";
}
```

### 2.4 常量注释

```java
/** 账单缴费状态：待缴 */
public static final int BILL_PAY_STATUS_UNPAID = 0;

/** 账单缴费状态：已缴 */
public static final int BILL_PAY_STATUS_PAID = 1;

/** 账单缴费状态：部分缴费 */
public static final int BILL_PAY_STATUS_PART = 2;
```

### 2.5 特殊处理注释

**业务规则、特殊处理必须注释原因**：

```java
// 水电费账单写入统一账单表时，规则ID根据类别确定：水费=4, 电费=2
// 此映射关系来源于收费规则配置，修改规则时需同步更新此处逻辑
Long ruleId = (bill.getCategory() != null && bill.getCategory() == CommonConst.FEE_CATEGORY_WATER) ? 4L : 2L;
```

### 3.4 数据表注释规范

**目的**：在页面代码中标注数据表名，帮助开发者快速定位页面对应的数据库表。

#### 3.4.1 注释格式

**标准格式**（单表）：
```html
<template>
  <!-- 数据表: water_elec_bill -->
  <div class="g-page-wrap water-elec-bill-wrap">
```

**多表关联格式**：
```html
<!-- 数据表: biz_fee_bill (关联: stall_info, biz_recv_pay_plan) -->
```

**位置规范**：注释位于模板首行，紧跟 `<template>` 标签之后。

#### 3.4.4 注意事项

1. **注释位置**：必须位于 `<template>` 后第一行，便于快速定位
2. **表名准确性**：以后端实体类 `@TableName` 注解为准，不要手动猜测
3. **格式统一**：使用 `<!-- 数据表: 表名 -->` 标准格式
4. **搜索友好**：注释内容包含 `数据表:` 前缀，便于全局搜索
5. **多表说明**：关联表使用 `(关联: 表1, 表2)` 格式追加
6. **不影响渲染**：HTML 注释不会被浏览器渲染，不影响页面样式和功能

## 五、禁止行为

| 禁止类型 | 错误示例 | 正确做法 |
|---------|---------|---------|
| 英文注释 | `// get user info` | `// 获取用户信息` |
| 冗余注释 | `i++; // i加1` | 直接写 `i++` |
| 过时注释 | `// TODO: 已实现` | 删除或更新 |
| 无意义注释 | `// 结束大括号 }` | 不写注释 |
| 中文标点混用 | `// 获取用户信息；` | `// 获取用户信息` |
