## 一、问题背景

### 1.1 审计合规的核心原则

财务流水是集团全域资金台账的唯一数据源，必须具备**"历史不可变"**属性：
- **任何时候查询同一笔流水，展示的数据应完全一致**（交易发生时是什么样子，现在还是什么样子）
- 金额、业务类型、流水单号等数值/枚举字段已在写入时固化（符合规范）
- 关联实体的展示文本（铺位名称、市场名称、分类名称、商户名称、缴费人姓名等）当前通过 ID 动态关联查询，**不满足"历史不可变"要求**

### 1.2 当前风险现状

#### 风险表一：`biz_finance_flow`（全域财务流水表）

**物业场景（water_elec/deposit）风险：**

| 字段 | 当前存储 | 风险 |
|---|---|---|
| `stall_id` | 仅存 ID | 铺位改名/改市场/改分类 → 历史流水展示变化 |
| `merchant_id` | 仅存 ID | 商户改名 → 历史流水展示变化 |
| `business_type` | 存枚举文本 ✅ | 不受影响 |
| 金额字段 | 写入时固化 ✅ | 不受影响 |
| `flow_no` | 写入时固化 ✅ | 不受影响 |

**查询链路**（`FinanceServiceImpl.toVO()`）：
```
BizFinanceFlow.stall_id
  → leaseStallService.getOptionsByIds(stallIds)  ← 实时查 stall_info
      → stallNumber / stallName / stallMarketName / categoryName  ← 当前状态（历史跳变风险）
```

**非物业场景（rent/deposit/marketing）风险——缴费人信息缺失：**

当前 `biz_finance_flow` 对租金（`rent`）、押金（`deposit`）等业务**未存储缴费人姓名、手机号、公司名称**。一旦租户信息变更（联系人改名、电话变更、企业更名），历史租金/押金流水无法追溯实际缴费人，审计合规存在缺口。

| 字段 | 当前存储 | 风险 |
|---|---|---|
| `contract_id` | ✅ 存 ID（`bill_id` 字段） | 合同存在即有记录 |
| `stall_id` | ✅ 存 ID | 铺位快照已补齐（v2.3 主目标） |
| `payer_name` | ❌ 无此字段 | 缴费人改名 → 历史流水无法追溯 |
| `payer_phone` | ❌ 无此字段 | 手机号变更 → 无法联系确认 |
| `payer_company_name` | ❌ 无此字段 | 企业更名 → 无法追溯实际缴费主体 |
| `payer_type` | ❌ 无此字段 | 个人/企业无法区分 |
| `contract_no` | ❌ 无此字段 | 仅有合同ID，报表无法直接展示合同编号 |

#### 风险表二：`water_elec_pay_record`（水电物业缴费记录表）

| 字段 | 当前存储 | 风险 |
|---|---|---|
| `stall_id` | 仅存 ID | 同上 |
| `merchant_id` | 仅存 ID | 同上 |
| `pay_amount` | 写入时固化 ✅ | 不受影响 |
| `flow_no` | 写入时固化 ✅ | 不受影响 |

**查询链路**（`WaterElecPayServiceImpl.page()`）：
```
WaterElecPayRecord.stall_id
  → leaseStallService.getOptionsByIds(stallIds)  ← 实时查 stall_info
      → stallNumber / stallName / stallMarketName / categoryName  ← 当前状态（历史跳变风险）
```

> **注**：`water_elec_pay_record` 属于物业场景，不涉及租金/押金/营销等缴费人场景，**不需要**缴费人快照字段。

### 1.3 已有正确实践（参照物）

项目中已有快照规范的正确实现，可作为升级标准：

| 表 | 字段 | 快照策略 |
|---|---|---|
| `water_elec_bill` | `category`、`unit_price` | 写入时固化，注释"规则修改不回溯" |
| `biz_discount_apply` | `policy_snapshot` | 审批时固化 JSON，注释"固化不回溯" |
| `biz_fee_bill_detail` | `fee_item_name`、`calc_mode`、`price` | 写入时固化快照 |

**结论**：`biz_finance_flow` 和 `water_elec_pay_record` 与上述规范存在一致性缺口，需补齐铺位/商户快照；`biz_finance_flow` 还需补齐缴费人快照，覆盖租金/押金/营销等物业外场景。

## 二、升级目标

1. **`biz_finance_flow`**：
   - 新增铺位、商户快照字段（物业场景，写入时固化，查询时直接读本表）
   - 新增缴费人快照字段（租金/押金/营销场景，写入时固化，覆盖物业外收费流水）
2. **`water_elec_pay_record`**：同步新增铺位、商户快照字段（仅物业场景）
3. **`biz_flow_seq`**（已在 v2.2 中建表）：保持不变
4. **前后端适配**：VO 和前端列同步更新

## 三、数据库变更

### 3.1 `biz_finance_flow` 表结构变更

#### 3.1.1 物业场景快照字段（铺位/商户）

| 字段名 | 类型 | 默认值 | 注释 |
|---|---|---|---|
| `stall_number` | varchar(64) | NULL | 铺位编号快照（写入时固化） |
| `stall_name` | varchar(128) | NULL | 铺位名称快照（写入时固化） |
| `stall_market_name` | varchar(128) | NULL | 所属市场名称快照（写入时固化） |
| `category_name` | varchar(64) | NULL | 租赁分类名称快照（写入时固化） |
| `merchant_name` | varchar(128) | NULL | 商户名称快照（写入时固化） |

适用业务类型：`water_elec`、`deposit`（涉及铺位/商户的押金流水）

#### 3.1.2 非物业场景快照字段（缴费人/合同）

> 专为租金（`rent`）、押金（`deposit`）、营销抵扣（`marketing`）等物业外收费流水设计，确保缴费人信息和合同信息写入时固化。

| 字段名 | 类型 | 默认值 | 注释 |
|---|---|---|---|
| `payer_name` | varchar(64) | NULL | 缴费人姓名（写入时固化，禁止修改） |
| `payer_phone` | varchar(32) | NULL | 缴费人手机号（写入时固化） |
| `payer_company_name` | varchar(128) | NULL | 缴费人公司名称（企业缴费时写入，个人为 null） |
| `payer_type` | tinyint | NULL | 缴费人类型 1个人 2企业（写入时固化） |
| `contract_no` | varchar(64) | NULL | 关联合同编号（租金/押金场景写入） |
| `contract_id` | bigint | NULL | 关联合同ID（已有 bill_id，此字段为语义化冗余，便于报表直接查询） |

适用业务类型：`rent`、`deposit`、`marketing`

> **为什么需要 `contract_id`？** `bill_id` 字段存的是合同 ID（字符串形式），`contract_id` 是 bigint 数值形式，便于按合同 ID 做索引查询和报表聚合，两者语义一致、数值相等。

#### 3.1.3 新增索引

| 索引名 | 字段 | 说明 |
|---|---|---|
| `idx_stall_id` | `stall_id` | 已存在（v2.0） |
| `idx_merchant_id` | `merchant_id` | 新增（按商户查询流水） |
| `idx_contract_id` | `contract_id` | 新增（按合同ID查询租金/押金流水） |
| `idx_payer_name` | `payer_name` | 新增（按缴费人姓名查询） |

## 九、附：与其他快照规范的统一性说明

| 表 | 快照字段 | 写入时机 | 约束 |
|---|---|---|---|
| `water_elec_bill` | `category`、`unit_price` | 账单生成时 | "规则修改不回溯" |
| `biz_discount_apply` | `policy_snapshot` | 优惠申请提交时 | "审批后计算依据，固化不回溯" |

| `biz_finance_flow`（本次 v2.3） | **物业快照**：`stall_number`、`stall_name`、`stall_market_name`、`category_name`、`merchant_name`<br>**非物业快照**：`payer_name`、`payer_phone`、`payer_company_name`、`payer_type`、`contract_no`、`contract_id` | 缴费/退费/押金写入时 | **"写入时固化，禁止修改"** |
