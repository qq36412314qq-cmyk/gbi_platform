# 物业费"自动生成记录"功能方案

> 创建时间：2026-09-05  
> 需求来源：feeBill.vue 新增"自动生成记录"按钮

---

## 一、需求概述

### 1.1 功能目标
在物业费账单管理页面新增"自动生成记录"按钮，实现按市场/时间范围批量自动生成物业费账单记录。

### 1.2 业务场景
- 每月月初/月末批量生成历史欠费账单
- 新铺位入驻后补录历史账单
- 排除已生成月份，避免重复

### 1.3 核心逻辑
```
目标月份（用户选择）
    ↓
从合约开始日期 → 目标月份（含）
    ↓
逐月查询是否已存在账单
    ↓
不存在则生成（含物业费规则的铺位）
```

### 2.3 核心算法设计

#### 步骤1：查询目标铺位列表
```java
// 查询市场下所有铺位（关联收费规则）

// 查询有物业费规则的铺位

    new LambdaQueryWrapper<FeeRuleStallRel>()
        .eq(FeeRuleStallRel::getFeeItemId, PROPERTY_FEE_ITEM_ID)
        .in(FeeRuleStallRel::getStallId, stallIds)
        .select(FeeRuleStallRel::getStallId)
).stream().map(FeeRuleStallRel::getStallId).toList();
```

#### 步骤2：查询合约信息
```java
// 查询生效中的合约，获取开始日期
List<StallContract> contracts = stallContractMapper.selectList(
    new LambdaQueryWrapper<StallContract>()
        .in(StallContract::getStallId, stallsWithFeeRule)
        .eq(StallContract::getContractStatus, 1) // 生效中
        .isNotNull(StallContract::getStartTime)
);

// 按铺位分组，取最早的开始日期
Map<Long, LocalDate> earliestStartMap = contracts.stream()
    .collect(Collectors.groupingBy(
        StallContract::getStallId,
        Collectors.mapping(StallContract::getStartTime, Collectors.minBy(LocalDate::compareTo))
    ));
```

#### 步骤3：计算待生成月份范围
```java
// 解析目标月份
YearMonth targetYm = YearMonth.parse(targetMonth);
YearMonth currentYm = YearMonth.now();

// 实际目标月份 = min(targetMonth, 当月)
YearMonth effectiveTarget = targetYm.isAfter(currentYm) ? currentYm : targetYm;

// 对每个铺位，计算从开始日期到有效目标月份的所有月份
for (Map.Entry<Long, LocalDate> entry : earliestStartMap.entrySet()) {
    Long stallId = entry.getKey();
    LocalDate startDate = entry.getValue();
    
    YearMonth startYm = YearMonth.from(startDate);
    YearMonth ym = startYm;
    
    while (!ym.isAfter(effectiveTarget)) {
        String monthStr = ym.toString(); // "2024-06"
        
        // 检查是否已存在账单
        long existCount = billMapper.selectCount(
            new LambdaQueryWrapper<PropertyFeeBill>()
                .eq(PropertyFeeBill::getCompanyId, companyId)
                .eq(PropertyFeeBill::getStallId, stallId)
                .eq(PropertyFeeBill::getBillMonth, monthStr)
        );
        
        if (existCount == 0) {
            // 生成账单
            generateSingleForStall(companyId, stallId, monthStr, rule);
            count++;
        }
        
        ym = ym.plusMonths(1);
    }
}
```

## 四、幂等性保证

### 4.1 多层防护
| 层级 | 防护方式 |
|------|----------|
| 调用前 | 查询已存在账单，跳过已有月份 |
| 生成时 | `generateSingle()` 内部已有幂等检查 |
| 数据库 | `company_id + stall_id + bill_month` 唯一约束（可选） |

### 4.2 重复执行安全性
- 同一目标月份重复点击 → 返回 0（已全部生成）
- 不同用户同时点击 → 分布式锁（可选，后续优化）

### 7.3 Service 实现核心
```java
@Override
@Transactional(rollbackFor = Exception.class)
public int generateAuto(PropertyFeeBillAutoGenerateDTO dto) {
    LoginUser loginUser = UserContext.getLoginUser();
    Long companyId = loginUser.getCompanyId();
    
    // 1. 确定目标月份（默认当月）
    String targetMonth = StringUtils.hasText(dto.getTargetMonth()) 
        ? dto.getTargetMonth() 
        : YearMonth.now().toString();
    
    // 2. 查询市场下铺位
    List<Long> stallIds = leaseStallService.listStallIdsByMarket(dto.getMarketId());
    if (stallIds.isEmpty()) return 0;
    
    // 3. 过滤有物业费规则的铺位
    List<Long> validStalls = feeRuleStallRelService.listStallIdsWithFeeRule(stallIds);
    if (validStalls.isEmpty()) return 0;
    
    // 4. 查询合约获取开始日期
    Map<Long, LocalDate> startDates = queryEarliestContractStart(validStalls);
    
    // 5. 逐月生成
    int totalCount = 0;
    for (Long stallId : validStalls) {
        LocalDate startDate = startDates.get(stallId);
        if (startDate == null) continue;
        
        YearMonth startYm = YearMonth.from(startDate);
        YearMonth endYm = YearMonth.parse(targetMonth);
        
        YearMonth ym = startYm;
        while (!ym.isAfter(endYm)) {
            String month = ym.toString();
            // 检查是否已存在
            long exist = billMapper.selectCount(
                new LambdaQueryWrapper<PropertyFeeBill>()
                    .eq(PropertyFeeBill::getCompanyId, companyId)
                    .eq(PropertyFeeBill::getStallId, stallId)
                    .eq(PropertyFeeBill::getBillMonth, month)
            );
            if (exist == 0) {
                // 生成（复用现有逻辑）
                PropertyFeeBillGenerateDTO singleDto = new PropertyFeeBillGenerateDTO();
                singleDto.setBillMonth(month);
                singleDto.setStallId(stallId);
                generateSingle(singleDto);
                totalCount++;
            }
            ym = ym.plusMonths(1);
        }
    }
    
    log.info("[自动生成] 完成，companyId={}, targetMonth={}, totalCount={}", 
        companyId, targetMonth, totalCount);
    return totalCount;
}
```

## 九、测试用例

### 9.1 正常场景
| 用例 | 输入 | 预期结果 |
|------|------|----------|
| 生成当月 | 不选月份 | 生成当月账单 |
| 生成历史 | 选择 2024-06 | 从合约开始到 2024-06 全部生成 |
| 排除已存在 | 选择已部分生成的月份 | 仅生成缺失月份 |
| 多铺位批量 | 多个铺位有合约 | 所有铺位按月份生成 |

### 9.2 边界场景
| 用例 | 输入 | 预期结果 |
|------|------|----------|
| 无规则铺位 | 市场无物业费规则 | 返回 0，提示"无有效铺位" |
| 无合约铺位 | 铺位无生效合约 | 跳过该铺位 |
| 重复执行 | 再次点击生成 | 返回 0，提示"已全部生成" |
| 未来月份 | 选择未来月份 | 限制到当月 |
