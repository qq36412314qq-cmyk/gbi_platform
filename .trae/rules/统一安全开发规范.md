# 统一安全开发规范

## 文档描述

本规范为集团多业态一体化管控系统全链路安全强制标准，覆盖后端、PC 前端、商户小程序、数据库、文件、第三方对接、权限、审计、财务资金、地图画布等高风险模块；对齐《整体业务方案》《后端编码规范》《前端开发规范》《权限多租户隔离规范》所有安全相关条款，单人独立开发统一安全落地标准，满足企业内控、等保基础合规要求，杜绝越权访问、数据泄露、注入攻击、资金篡改、恶意上传、高危操作无追溯等安全漏洞。

## 一、安全整体设计原则

1. **分层纵深防护**：登录鉴权→接口功能权限→数据租户隔离→参数校验→传输加密→存储加密多层防护，单一防线失效仍有兜底拦截。

2. **最小权限原则**：账号、角色仅分配岗位必需功能 / 数据权限，禁止超范围赋权；高危操作独立权限 \+ 双人复核。

3. **全程可审计追溯**：所有敏感、高危操作强制写入审计日志，永久存储不可删除。

4. **输入全过滤原则**：前后端双重过滤 SQL、XSS、JSON 注入恶意字符，不信任任何前端传入参数。

5. **数据分级防护**：公开普通业务数据、商户隐私数据、财务资金数据、系统密钥区分加密 / 脱敏策略。

6. **环境隔离原则** 开发 / 测试 / 生产环境配置、密钥、访问权限严格分离，禁止混用配置文件。

## 二、后端接口安全规范（SpringBoot 全局强制）

### 2\.1 统一登录与 Token 鉴权

1. 全部业务接口无例外接入 JWT 全局拦截器，无 token、token 过期、篡改 token 直接返回 401，拒绝业务执行。

2. Token 内置`userId、companyId、角色集合、权限集合`，服务端校验签名，禁止前端篡改身份。

3. 支持账号主动下线、异地登录强制清空原有 token；敏感操作（修改密码、删除地图）二次弹窗验证码校验。

4. 生产环境 token 有效期合理管控，长期闲置自动失效。

### 2\.2 功能 RBAC 接口权限拦截

1. 所有 Controller 方法必须添加`@PreAuthorize("xxx:xxx")`权限注解，无权限直接拦截返回 403，**不依赖前端隐藏按钮做安全控制**。

2. 铺位地图高危操作专属权限管控：`stall:map:edit`（底图替换、批量点位修改、删除地图）归为敏感权限，开通需二级双人复核。

3. 财务导出、全平台审计日志、集团全域数据大屏等高危查看权限单独管控。

### 2\.3 多租户数据越权防护（核心安全防线）

1. MyBatis-Plus 自定义拦截器自动拼接`company_id`过滤条件，所有列表查询默认隔离其他子公司数据。

2. 集团管理员自动关闭过滤；跨子公司调拨、全域报表需手动关闭拦截，代码注释 \+ 审计记录留痕。

3. 画布点位保存接口强制校验 stall 所属`company_id`与当前登录账号一致，禁止跨公司绑定铺位。

4. 前端传入 company\_id 参数后端全部丢弃，仅从 JWT 上下文读取，杜绝参数篡改越权。

### 2\.4 请求参数安全校验

1. 所有入参统一使用 DTO，搭配`@NotBlank、@NotNull、@Pattern、长度限制`注解，非法参数直接返回 400，不执行业务逻辑。

2. 后端统一工具过滤`<script>、onload、select、union`等 XSS、SQL 注入、JSON 注入关键字。

3. 铺位地图`saveMapPoints`接口对点数字符串做特殊字符清洗，防止恶意脚本入库、前端画布 XSS 攻击。

4. 禁止任何接口直接拼接 SQL 字符串，全部使用 MyBatis-Plus 参数化查询，彻底防注入。

### 2\.5 接口幂等与防重复提交

1. 资金类：缴费、退费、租金核销、营销优惠核销强制幂等，通过唯一 requestId \+ 业务单号双重校验。

2. 地图批量点位保存、批量删除、批量导出接口增加防重复提交控制。

3. 前端提交按钮临时禁用，后端二次兜底拦截重复请求。

### 2\.6 接口限流防护

基于 Redis 实现单账号、单 IP 限流：

- 登录接口：限制短时间多次尝试，防止暴力破解密码；

- 批量导出、地图全量点位查询、全域报表接口限流，避免刷库拖垮数据库。

### 2\.7 全局异常安全屏蔽

1. 生产环境禁止抛出 SQL 堆栈、代码路径、服务器信息给前端。

2. 自定义业务异常友好提示，区分参数错误、权限不足、数据不存在，不泄露底层系统细节。

## 三、数据库安全开发规范

### 3\.1 账号与配置安全

1. 数据库账号、密码加密存放于 yml 配置，禁止明文写代码、禁止提交代码仓库。

2. 数据库仅开放应用服务器白名单，禁止公网直连数据库。

3. 区分开发库、生产库账号权限，生产库无 drop、alter 高危权限。

### 3\.2 数据表与数据安全

1. 所有业务表必须携带`company_id`实现租户隔离，全局公共配置表除外。

2. 统一开启 MyBatis-Plus 逻辑删除，财务、合同、审计、地图数据**永久禁止物理删除**。

3. 敏感字段加密存储：商户身份证、手机号、用户登录密码（BCrypt 加密）、第三方密钥。

4. 市场地图`market_map`、点位表`map_stall_point`点位 JSON 字段做内容过滤，禁止恶意 HTML 入库。

5. 定期自动全量备份数据库，备份文件加密存储，保留 7 天以上可回滚记录。

### 3\.3 SQL 安全红线

1. 禁止动态拼接 SQL、禁止 $\{\} 直接拼接用户输入，统一 \#\{\} 参数占位。

2. 联表、复杂统计 SQL 统一放入 mapper\.xml，后端做参数过滤。

3. 禁止接口直接支持模糊全库查询，防止批量拖库泄露商户、铺位数据。

## 四、文件上传 / OSS 存储安全规范（含地图底图）

1. 统一上传工具`OssUtil`后端校验文件后缀：仅允许 jpg/png/webp/pdf/doc/xlsx；拦截 exe/html/js/svg 等危险文件。

2. 底图上传（铺位地图模块）前端压缩、后端二次校验尺寸、格式、文件大小上限。

3. OSS 配置私有读写权限，不开放公共读；文件访问生成时效临时链接，过期失效。

4. 所有上传文件自动绑定`company_id`，分公司文件逻辑隔离，禁止跨公司访问附件。

5. 上传文件名称重命名，避免路径穿越、文件名注入漏洞。

6. 地图底图、合同附件、巡检照片删除仅做逻辑标记，OSS 资源不立即删除，留存追溯周期。

## 五、前端安全规范（Vue3 PC \+ 商户小程序）

### 5\.1 传输与存储安全

1. 生产环境全站 HTTPS，禁止 HTTP 明文传输接口数据。

2. Token 仅存放 Pinia\+localStorage，退出登录、账号禁用时清空全部本地缓存。

3. 商户身份证、完整手机号、财务金额等敏感信息不持久化本地。

4. 小程序禁止缓存账单、商户隐私数据，清除缓存需重新登录。

### 5\.2 XSS 防护

1. 页面渲染数据自动转义特殊字符；画布点位渲染前过滤脚本标签。

2. 新增 / 编辑、地图点位提交前前端预过滤恶意 HTML，双层防护后端校验。

3. 禁止使用 v\-html 渲染用户提交的铺位备注、地图自定义文本。

### 5\. 按钮与数据安全

1. 所有新增 / 删除 / 导出 / 地图编辑按钮强制`<AuthBtn>`鉴权，禁止 v\-if 手动判断权限绕过管控。

2. 手机号、身份证统一调用`formatPhone`脱敏展示，仅管理员账号可查看完整信息。

3. 前端不处理 company\_id 过滤，仅做页面隐藏，真实数据隔离由后端兜底。

### 5\. 画布专项安全（Fabric 地图模块）

1. 点位 JSON 提交前过滤`<script>、eval、onclick`等事件脚本。

2. 画布加载后端返回点位数据自动清洗，防止恶意 DOM 渲染。

3. 禁止前端本地存储完整市场点位 JSON，刷新页面必须重新请求后端接口。

## 六、权限风控与二级复核安全规范

1. 普通权限（地图查看、导出）单人操作即时生效，仅记录基础操作日志。

2. 敏感高危权限（stall:map:edit、财务全域查看、全局配置）必须走二级双人复核流程：

    - 集团运维发起申请；

    - 权限暂存不生效；

    - 集团超级管理员审核通过后权限才生效。

3. 岗位权责分离：操作岗无审批权限，复核岗无日常运维权限，杜绝单人闭环操作风险。

4. 权限变更完整记录：操作人、复核人、IP、变更前后权限存入审计日志永久留存。

## 七、财务资金专项安全规范（最高安全等级）

1. 所有收支流水强制写入`finance_fee_pay_bill`统一流水表，禁止各业务自建资金台账。

2. 缴费、退费、营销优惠核销全部添加事务，异常完整回滚，杜绝错账、重复扣款。

3. 支付接口幂等校验，支付回调参数签名校验，防止伪造支付订单。

4. 财务流水仅支持查询导出，无任何编辑、删除接口，永久归档不可篡改。

5. 大额退费、跨公司财务查看权限属于敏感权限，需二级复核。

6. 财务数据导出操作单独记录审计日志，记录导出人、导出时间、数据范围。

## 八、第三方对接安全规范（钉钉 / 金蝶 / 智能表 / OSS）

1. 第三方 AppKey、Secret、接口地址全部加密存入 yml，禁止硬编码前后端代码。

2. 所有第三方接口请求增加签名 \+ 时间戳校验，防止伪造调用。

3. 调用失败统一重试（最多 3 次），调用日志入库便于对账排查。

4. 金蝶财务凭证推送、钉钉考勤同步等核心第三方操作，同步写入审计日志。

5. 第三方返回商户、铺位敏感数据后端脱敏后再返回前端。

## 九、全链路审计日志安全规范（合规核心）

### 9\.1 强制记录操作清单

1. 账号类：登录、退出、密码修改、账号启用 / 禁用；

2. 权限类：角色、权限变更、敏感权限二级审核全流程；

3. 地图专项：底图上传 / 替换、画布点位保存、地图删除、地图导出；

4. 业务类：铺位新增 / 删除、合同签署 / 退租、批量操作；

5. 财务类：缴费、退费、核销、财务导出、凭证同步；

6. 系统配置：全局参数、流程模板、UI 主题修改、第三方密钥变更；

7. 文件类：批量导出、大量附件下载。

### 9\.2 审计日志字段标准

操作人 ID、操作人姓名、所属 company\_id、操作 IP、操作模块、操作类型、操作前 JSON、操作后 JSON、操作时间、审核人（敏感权限专用）。

### 9\.3 日志访问权限隔离

1. 集团超级管理员：查看全平台所有审计记录，支持导出；

2. 子公司管理员：仅查看本 company\_id 业务日志；

3. 普通员工、商户无审计日志页面访问权限。

### 9\.4 日志存储安全

审计数据表禁止逻辑 / 物理删除，数据永久归档，满足财务、内控、等保溯源要求。

## 十、环境区分安全规范

1. 开发环境：开启 SQL 打印、简化日志、可使用测试密钥；禁止连接生产数据库。

2. 生产环境：

    - 关闭 SQL 控制台输出；

    - 密钥加密配置；

    - 关闭测试接口、调试接口；

    - 开启限流、完整审计、全 HTTPS；

3. 配置文件严格分离，禁止 dev 配置打包至生产 jar；Maven 打包自动过滤开发环境配置。

## 十一、部署与运维安全规范

1. 生产服务器禁止开放外网远程端口，仅内网运维访问。

2. Nginx 统一配置 HTTPS、X\-Frame\-Options、防劫持头部。

3. 项目 jar 包、前端 dist 包版本留存，故障可快速回滚，回滚后核对财务、地图核心数据完整性。

4. 服务器定期补丁更新，最小化开放端口。

## 十二、开发强制安全红线（禁止行为）

1. 禁止接口、页面绕过 company\_id 租户过滤，实现跨子公司数据访问；

2. 禁止硬编码数据库密码、第三方密钥、token 密钥；

3. 禁止拼接 SQL、前端输入直接渲染不做 XSS 过滤；

4. 禁止地图点位、财务敏感数据本地持久化存储；

5. 高危地图 / 财务权限单人直接开通，不接入二级复核；

6. 上传接口不校验文件后缀，允许可执行脚本文件；

7. 生产环境返回代码堆栈、数据库错误详情至前端；

8. 资金操作无事务、无幂等控制，存在重复入账风险；

9. 审计日志可删除、定期清理，破坏追溯能力；
10 集团账号赋予子公司业务编辑权限，越权修改商户 / 地图数据。
