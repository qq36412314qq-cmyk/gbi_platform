### 1.3 表名区分说明

`finance_fee_pay_bill`（统一账单）与 `finance_pay_order`（缴费单）是两张不同语义的表：

| 表名                  | 含义                                      |
|-----------------------|-------------------------------------------|
| finance_fee_pay_bill  | 各业务类型（物业费/水电费/租赁费等）的应收账单 |
| finance_pay_order     | 用户发起聚合支付后生成的缴费单，是支付载体     |
| finance_pay_order_item| 缴费单的收费明细快照（幂等固化，生成后不可改） |

### 4.2 Entity 文件批量替换命令

在项目根目录执行以下 PowerShell 命令（一次性替换所有 Entity 的 @TableName）：

```powershell
$base = "D:\Office\Project\Java\gbi_platform\gbi_platform_server\src\main\java\com\gbi\platform\entity"

$replacements = @(
  @("MarketInfo.java",        'market_info',         'property_market'),
  @("PropertyFeeBill.java",   'property_bill',       'property_fee_bill'),
  @("StallCategory.java",     'stall_category',      'property_stall_category'),
  @("StallContract.java",     'stall_contract',      'property_stall_contract'),
  @("StallInfo.java",         'stall_info',          'property_stall_info'),
  @("StallTenant.java",       'stall_tenant',        'property_stall_tenant'),
  @("WaterElecBill.java",     'water_elec_bill',     'property_water_elec_bill'),
  @("WaterElecMeter.java",    'water_elec_meter',    'property_water_elec_meter'),
  @("WaterElecPayRecord.java",'water_elec_pay_record','property_water_elec_pay_record'),
  @("BizFeeBill.java",        'biz_fee_bill',        'finance_fee_pay_bill'),
  @("FeeItem.java",           'biz_fee_item',        'finance_fee_item'),
  @("FeeRule.java",           'biz_fee_rule',        'finance_fee_rule'),
  @("FeeRuleStallRel.java",   'biz_fee_rule_stall_rel','finance_fee_rule_stall_rel'),
  @("BizFinanceFlow.java",    'biz_finance_flow',    'finance_pay_flow'),
  @("BizFinanceWriteoff.java",'biz_finance_writeoff','finance_writeoff'),
  @("BizPayBill.java",        'biz_pay_bill',        'finance_pay_order'),
  @("BizPayBillItem.java",    'biz_pay_bill_item',   'finance_pay_order_item'),
  @("BizRecvPayPlan.java",    'biz_recv_pay_plan',   'finance_recv_pay_plan'),
  @("BillPlanRel.java",       'bill_plan_rel',       'finance_pay_plan_rel'),
  @("BizDiscountApply.java",  'biz_discount_apply',  'finance_discount_apply'),
  @("BizDiscountPolicy.java", 'biz_discount_policy', 'finance_discount_policy')
)

foreach ($r in $replacements) {
  $file = Join-Path $base "$($r[0])"
  $content = Get-Content $file -Raw -Encoding UTF8
  $old = $r[1]
  $new = $r[2]
  $updated = $content -replace "@TableName\(`"$old`"\)", "@TableName(`"$new`")"
  if ($updated -ne $content) {
    Set-Content $file $updated -Encoding UTF8NoBOM
    Write-Output "已更新: $($r[0])  `"$old`" -> `"$new`""
  } else {
    Write-Output "无需更新: $($r[0])"
  }
}
```

### 4.3 验证 @TableName 更新结果
